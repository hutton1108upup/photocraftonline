## 实测与证据边界

- 本地 Chrome 使用本站未修改的 WebAssembly 构建 `72921900975c7e6f`。
- 打开原创 640 × 400 练习 PNG，复制 Background 图层，在副本上画黑线。
- `File → Save As…` 下载 `practice-image.psd`；重新打开后通过截图确认 `Background copy`、`Background` 与笔刷修改保留。
- 重开后导出 PNG，尺寸仍为 640 × 400。样例像素从 RGB(22, 78, 71) 变为 RGB(0, 0, 0)，确认修改进入导出结果。
- 该流程观察到的请求均为本地 GET，没有非 GET 或外部主机请求。此观察不能认证其他功能、桌面程序、正式站未来版本或第三方网站。
- 未运行 Photoshop 同文件对照、性能比较、复杂 PSD、文字、蒙版、透明背景及逐系统安装测试。页面明确保留这些限制。

新增公开截图：`public/assets/tutorial/save-and-reopen-psd.png`。使用本站原创练习图片，不含用户文件或账号信息。

需要重新启动时，在本工作树目录打开 PowerShell，依次执行：

```powershell
npm.cmd run build:production
npm.cmd run check:production
node scripts/server.mjs --production --port 4196
```
