# GitHub 上传范围

目标：`hutton1108upup/photocraftonline`。此仓库是公开仓库。

## 可以上传

- `src/`：可编辑页面、共用导航页脚、浏览器交互、样式、网站文字与构建资源清单。
- `public/`：公开图片字体、未修改的原版编辑器、必需的第三方许可证。
- 明确列出的构建、检查和本地预览脚本。
- `package.json`、`package-lock.json`、`site.config.json`、`wrangler.jsonc`。
- README、第三方声明、使用文档、质量检查工作流与本地启动入口。

## 排除，不上传

- `.local/`：本地进程 PID、日志、临时 Cloudflare 结果、上传审查证据。
- `evidence/`：截图、浏览器检查记录；可能带有电脑本地信息。
- `reference/`：原网页 HTML 和 Next.js 渲染快照；它们仅供本地对照，运行不再依赖该目录。
- `dist/`：构建产物；由 CI/Cloudflare 重新生成。
- `node_modules/`、`.wrangler/`、`__pycache__/`、日志和压缩包。
- `.env*`、`.dev.vars*`、私钥与凭据文件、Token 文本。
- `scripts/capture.py`：会覆盖页面的本地基准采集工具；不是部署依赖。
- `photocraft.txt`：原有的本地备注文件。

`scripts/audit-upload.mjs` 使用显式允许清单，并扫描实际文件或 Git 暂存区
中的已知凭据模式。检测结果只记录文件、位置、原因，不打印匹配的秘密值。
检查无命中并不等于数学证明；上传文件仍须逐类审查。

Git 提交身份使用 GitHub 的 noreply 邮箱，不公布本机配置中的私人邮箱。
`wrangler.jsonc` 可以提交账号 ID 与域名；它不应包含任何 API Token。
