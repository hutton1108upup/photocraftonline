## 本地查看

生产预览：英文 <http://localhost:4198/>，中文 <http://localhost:4198/zh>。

需要重新启动时，在此工作树 PowerShell 依次运行：

```powershell
npm.cmd run build:production
npm.cmd run check:production
node scripts/server.mjs --production --port 4198
```

成功应看到 `Built 36 production pages`、`PASS production` 和 `PhotoCraft local preview: http://localhost:4198 (36 pages)`。失败停在对应步骤；端口占用时先核对项目，不停止未知进程。

提交 GitHub、合并 `main` 与部署是不同状态。本轮授权范围截至提交 GitHub；GitHub CI 不会自动完成正式站部署。
