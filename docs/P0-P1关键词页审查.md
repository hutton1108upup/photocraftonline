```powershell
npm.cmd run build:production
npm.cmd run check:production
node scripts/server.mjs --production --port 4197
```

成功提示应为 `Built 36 production pages`、`PASS production`、`PhotoCraft local preview: http://localhost:4197 (36 pages)`。任一步失败就停在该步；端口被占用时核对当前项目，不停止未知进程。
