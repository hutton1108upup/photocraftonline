What is SolidCraft?

SolidCraft is an open-source parametric 3D CAD application written in Rust. Draw a sketch on a plane, add dimensions and constraints, then turn its profiles into a solid. Change a parameter to rebuild the feature timeline. Start with parts such as mounting plates, brackets and simple enclosures.

Desktop packages are available for Windows, macOS and Linux, alongside a browser app and CLI. The project is still developing: completing a simple part does not establish coverage of an entire industrial workflow.

SolidCraft, SolveCraft and CADCraft

SolveCraft was the earlier name. Older guides may mention solvecraft-cli and .solvecraft. New workflows use solidcraft-cli and .solidcraft. Back up older designs before following the official migration notes.

Our CADCraft guide covers a different drafting application with an AutoCAD-style command workflow. SolidCraft focuses here on parametric 3D parts. The Craft app directory links related tools; similar names and separate repositories do not establish an official affiliation.

Common questions

Is this an official SolidCraft site?

No. Use the upstream GitHub repository for official releases, issues and documentation. This site provides independent guides and an original worked example.

Does the application have a Chinese interface?

A Chinese tutorial and the application interface language are separate things. This guide uses English interface labels with Chinese explanations in its Chinese edition. Check the language settings in your downloaded version for available interface languages.

Is it an official version of Fusion 360?

No. SolidCraft is an independent open-source project and is not affiliated with Autodesk. Evaluate it against your own files, required operations and deliverables.
