Install PhotoCraft with the MSI

  1. Download the MSI matching your system type and follow the checksum steps.
  2. Double-click the MSI in Explorer. Upstream packaging defines an install-folder screen, confirmation, progress and finish screens, with PhotoCraft under Program Files by default.
  3. Review the folder and prompts. Complete the system confirmation if you intend to install this package.
  4. Open PhotoCraft from Start, choose File → Open and use a practice image to check the canvas, then inspect an exported result.

A working app window and sample image are the success check; an installer completion message alone is insufficient. Wizard details come from upstream packaging at the release tag. We did not run an MSI installation acceptance test.

Run the Portable ZIP without an MSI Installation

  1. Choose the file containing windows, your architecture and portable.zip. GitHub Source code ZIP and the Web ZIP are different packages.
  2. Right-click the ZIP in Downloads → Extract All. Extract the complete folder somewhere writable; do not run the app inside the archive.
  3. Open the extracted subfolder and run photocraft.exe. Keep portable.txt and the other files beside it.
  4. Open a practice image with File → Open, export to a separate file and reopen the result.

Upstream portable.txt says portable preferences, brush presets and recovery files use PhotoCraftData beside the executable. Upstream notes that a read-only application folder can fall back to %APPDATA%\Photocraft. Confirm the data location and preserve the whole folder when moving or updating. Recovery files do not replace saved work.

Updates, Removal and Keeping Your Work

Before updating, save originals, editable documents and exports in a separate work folder and back them up. Check the latest release, match your system and architecture again, and verify its checksum. This page pins checked v0.10.0 files; it does not update your installation automatically.

For an MSI installation, Windows 11 uses Settings → Apps → Installed apps → PhotoCraft → Uninstall; Windows 10 uses Apps & features. If that route is unavailable, consult Microsoft’s removal instructions. Do not assume uninstalling backs up work or preserves all settings.

Close a portable copy before moving its full folder. Back up work and any needed PhotoCraftData separately before removing it. Extract an update into a different folder and check it before replacing your only copy.

PhotoCraft Windows FAQ

Is the Windows download paid?

These links point to upstream open-source releases with no download purchase on this site. See the source guide for licenses.

Can I select x64 without checking?

Read System type first. A default selection cannot confirm your architecture.

Can these files run on a phone?

They are Windows desktop packages, not Android APKs or iOS apps.

Does a failed save always mean a bad installation?

No. Format, permissions, fonts and effects may need separate checks. Keep your original and inspect the actual message.
