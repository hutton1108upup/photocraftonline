Windows: Download, Extract and Open a Sample

  1. In Settings → System → About, check whether your system is x64, ARM64 or 32-bit. The check below used the x64 Portable ZIP.
  2. Download the matching ZIP and verify its SHA256 below. Right-click → Extract All, then open the fully extracted application folder. Do not run the app inside the archive.
  3. Run solidcraft.exe and confirm v0.16.2 at the upper right. If you chose MSI, follow its installer and open from Start instead; we did not test MSI installation.
  4. Download the 60 mm editable sample. Choose File → Open in SolidCraft and select it, keeping the original.

Success check: a plate with two through-holes is visible, MountingPlate appears in the model tree, and the running version is v0.16.2. We opened this file through the local app control interface and measured one body with a 60 × 30 × 4 mm bounding box. This does not establish MSI, other-platform or full modeling compatibility.

If your system refuses to launch the app, check the source, checksum, architecture and extracted files first, then consult the current official launch instructions. Do not substitute an unknown download because of a system prompt.

macOS and Linux: Start the Package You Downloaded

macOS DMG

  1. Open the Universal DMG and drag SolidCraft.app into Applications.
  2. Launch from Applications; consult upstream instructions for first-launch system prompts.
  3. Open a sample, check the model and save your own copy.

Linux AppImage

Run uname -m first. For x86_64, run these commands in the download folder. Other architectures require the exact matching filename. DEB, RPM and Flatpak follow their own installation instructions, not these AppImage commands.

chmod +x solidcraft-0.16.2-linux-x86_64.AppImage
./solidcraft-0.16.2-linux-x86_64.AppImage

Success means the app opens a sample design. These Mac/Linux steps follow official documentation; startup on those systems was not tested here.

Verify the Same Version and Filename with SHA256

Open PowerShell in the folder containing the Windows ZIP and run:

Get-FileHash .\solidcraft-0.16.2-windows-x64-portable.zip -Algorithm SHA256

Compare the result with SHA256SUMS.txt from the same release. Our downloaded x64 portable package matched:

c1cdc511ec70a77536cb22bbcea5c9bcda6e0d29622fc5cb9c935d9a1c3977ef

A different filename, version or architecture needs its own checksum. File integrity does not establish complete feature coverage.

Upgrade an Older Version: Back Up, Then Download Manually

  1. Copy your .solidcraft designs and keep the old application and original files.
  2. The updater in v0.14.0 and earlier may not follow the repository move. Follow the official migration notes and download a current release manually.
  3. Open a design copy in the new app, check dimensions, bodies and timeline, then save with a new filename. Do not assume newer files can reopen in older software.

Our v0.12.0 mounting-plate and MCP tutorials retain their original steps. v0.16.2 opened the 60 mm sample in this check; we did not revalidate all old scripts, parameter edits or exports. Read current compatibility guidance.

If SolidCraft Will Not Open, Separate App and File Problems

  • No application window: check OS/CPU, checksum and complete extraction; record the exact error.
  • A window opens but the model is missing: open our small sample and compare the tree and version with the screenshot.
  • Only your design fails: keep the original and check its creator version against upstream compatibility guidance.
  • For a report, record the version, OS, GPU and error; keep private designs out of public Issues.
