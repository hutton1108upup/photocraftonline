Windows: run the portable build

  1. Confirm x64 in Settings → System → About, then download the portable ZIP above.
  2. Right-click the ZIP → Extract All. Extract the whole folder into Downloads or your own working directory; do not run it from inside the archive.
  3. Open the extracted directory and run solidcraft.exe. The same directory contains solidcraft-cli.exe, used in the tutorial.
  4. Check v0.12.0 in the title bar and open mounting-plate-60.solidcraft from the tutorial to confirm startup and file reading.

Upstream states that builds are unsigned. If SmartScreen appears, first confirm the source and checksum; after verification, upstream documents More info → Run anyway. For MSI, complete the installer and launch from the Start menu.

macOS and Linux installation

macOS

  1. Open the DMG and drag SolidCraft.app into Applications.
  2. Launch from Applications. Follow the official installation notes for first-launch system prompts.
  3. Open a sample design and confirm that the solid displays, then save your own copy.

Linux AppImage

  1. Use uname -m to identify your architecture and download its AppImage.
  2. Place it in your own application directory and allow execution in file properties, or use the command below.
  3. Launch and open a sample file. For Flatpak, Snap and distribution packages, follow their specific official instructions.
chmod +x solidcraft-0.12.0-linux-x86_64.AppImage
./solidcraft-0.12.0-linux-x86_64.AppImage

Checksums and upgrades

In Windows PowerShell, open the folder containing the ZIP and run the command below. Compare the result with the same filename in SHA256SUMS.txt from that release. The expected portable-package value follows.

Get-FileHash .\solidcraft-0.12.0-windows-x64-portable.zip -Algorithm SHA256
# 2c66701d4c66630f3d1988e43ceaf5c4b2179baf89dddb15ea70b3e03a0e24c1

Make a copy of designs before upgrading. Designs saved by v0.12.0 cannot be opened by v0.11.x or earlier. Use a copy for migration. Consult the compatibility notes for the earlier SolveCraft name and Flatpak application-ID changes.

If it does not start

  1. Confirm that the package matches your OS and CPU, and that the portable archive is fully extracted.
  2. For browser graphics failures, try the ?webgl URL documented upstream; export copies of existing work first.
  3. If solidcraft-cli is not found, use .\solidcraft-cli.exe in its directory, or set its full executable path in the client.
  4. Record the version, OS, GPU and exact error, then search the official Issues.
