Verify a PhotoCraft Download Before Installing

  1. Start at the upstream GitHub Releases page. Choose a release and an asset matching your operating system and architecture. Avoid a file from an unrelated mirror.
  2. Download the asset and SHA256SUMS.txt from the same release, when that release provides a checksum file. The checksum entry must match your exact filename.
  3. On Windows, right-click the downloaded file in Explorer and choose Copy as path (older versions may require Shift + right-click). Open PowerShell and run the command below after replacing the placeholder with that full path. Keep one pair of quotes around the path; remove any extra pair included by Copy as path.
  4. Compare the displayed SHA256 hash with the matching entry in the checksum file. Letter case does not matter. A mismatch means stop: check the release, filename and download again.
Get-FileHash -Algorithm SHA256 -LiteralPath 'PASTE_DOWNLOADED_FILE_PATH_HERE'

A matching hash shows that the file agrees with the published checksum. It does not prove that the program is harmless. If your operating system shows a publisher or security warning, investigate that specific warning; do not disable protection to finish installation. Does This Browser Editor Upload Your Files?

In a desktop Chrome local preview, we opened a 640 × 400 PNG, duplicated a layer, painted a line, saved a two-layer PSD, reopened it and exported a PNG. The test observed no image-upload request, no non-GET request and no request to an external host. The exported pixel retained the edit. Repeat the sample workflow.

The site code has no image-upload endpoint. These observations cover the tested build and operations; they do not establish the behavior of every tool, another website, a future update or the desktop app.

Loading this website still sends ordinary page and asset requests to its host, including information needed to serve them. Theme preferences may use browser storage. Production content pages configure GA4 page and key-click measurement, and hosting may provide Cloudflare Web Analytics. Our editor routes and local previews do not load GA4. No Clarity, advertising tags or session replay are configured. External community and download links use their own services. Read the full privacy notice.

Keep Your Original and Check the Output

Use a copy of an important document. A successful import does not prove that fonts, masks, smart objects, color profiles or all layer effects will survive saving. Our simple PSD check retained two pixel layers and a brush edit; it was not a Photoshop compatibility certification.

Download your output, reopen it and inspect the result before closing the editor. A browser tab or stored preference is not a backup. Files from unknown sources can also cause parser errors or excessive resource use; open-source software still needs updates and careful file handling.

Where to Report a Security Concern

For an upstream engine vulnerability, follow the project’s security policy. It describes the reporting process and current limitations. Do not place private documents, credentials or exploitable samples in a public issue.

For ordinary editor bugs, use upstream Issues with the build, browser and safe reproduction steps. That tracker belongs to the upstream project and is not a private website support inbox.

PhotoCraft Safety Questions

Does open source mean PhotoCraft is guaranteed safe?

No. It allows source inspection and reuse under the relevant license; build provenance, dependencies, document handling and updates still matter.

Is FreePhotoCraft.online the official PhotoCraft website?

No. We independently host a browser build and publish guides. Verify the upstream repository separately.

Can I use confidential client files?

Our sample test is not a certification for confidential workflows. Check your organization’s requirements and the exact build and operations before using sensitive documents.
