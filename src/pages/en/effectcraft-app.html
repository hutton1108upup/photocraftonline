What Is EffectCraft and Who Should Try It?

EffectCraft is ArtCraft’s free, open-source motion graphics and compositing tool, written in Rust and targeting a familiar After Effects-style workflow. Start with titles, shape animation and layered compositions. Upstream also documents expressions, effects, 3D cameras and lights; we have not validated their full behavior.

The v0.9.2 README labels it alpha and says it is not yet a replacement for After Effects on client work. This is an independent guide website hosting PhotoCraft and CADCraft, not an EffectCraft online editor or an official Adobe or ArtCraft service.

Installation Overview and Startup Check

  1. Windows MSI: verify the file and SHA256, then run the matching installer and follow its prompts. Portable ZIP: use Extract All and run effectcraft.exe from the fully extracted folder, not inside the archive.
  2. Mac: open the official DMG in Finder, follow the package’s instructions to place the app in Applications, then launch it there.
  3. Linux AppImage: in the download-folder terminal run chmod +x with the actual downloaded filename, then run that file.
  4. After startup, open our native sample and inspect its composition, two layers and two keys. Save a separate copy and check rendered output; installer completion alone does not validate the workflow.

On October 13, 2026 we verified opening, editing position keys, Save As, reopening and GIF export through the render queue in the Windows 11 x64 portable desktop app, and retested its CPU CLI. MSI, Mac/Linux installation and Launcher remain untested. For graphics-device or startup failures, record system, GPU, version and the complete message, then examine upstream Issues. Verify files against the same release’s checksum list; a matching hash does not guarantee every environment runs them.

EffectCraft Download and Usage FAQ

Can I directly open an AE template?

Do not assume so. Upstream v0.9.2 documents no .aep/.aepx, .mogrt/.ffx or AE plugin support. Our sample is native .ecproj.

Do ordinary users need Rust?

No Rust installation is needed for official desktop binaries or their CLI. Compiling source is a separate task.

Can EffectCraft run on this website?

This site supplies guides and samples and hosts PhotoCraft and CADCraft. Upstream Web ZIP is for self-hosting.

Can I use the tutorial shortcuts?

We tested Ctrl+O to open and P for Position on Windows v0.9.2. Save As and Add to Render Queue were tested through menus, which display Ctrl+Shift+S and Ctrl+M. The tutorial includes mouse paths; other systems’ keys were not tested.
