macOS

Recommended

Universal disk image (.dmg)

Also available

Apple Silicon and Intel in one file

Open GitHub Releases

  1. On GitHub Releases, under Assets, download the file ending in _universal.dmg.
  2. Open the .dmg and drag PhotoCraft into your Applications folder.
  3. If macOS blocks the app, open System Settings → Privacy & Security → Open Anyway.

Windows

Recommended

64-bit installer (.msi)

Also available

Portable .zip (no install)

Open GitHub Releases

  1. On GitHub Releases, under Assets, download the .msi installer (or .zip for portable).
  2. Run the installer and follow the setup wizard.
  3. Launch PhotoCraft from the Start menu or desktop shortcut.

Linux

Recommended

AppImage (x86_64)

Also available

.deb, .rpm, or tarball on Releases

Open GitHub Releases

  1. On GitHub Releases, under Assets, download the .AppImage file.
  2. Make it executable: chmod +x PhotoCraft_*.AppImage
  3. Run the AppImage, or install .deb / .rpm if you prefer a package manager.

How to download from GitHub

All desktop builds are published on the official GitHub Releases page.

  1. 1

    Open the PhotoCraft Releases page on GitHub.

  2. 2

    Select the latest release (marked Latest).

  3. 3

    Scroll down and expand the Assets section.

  4. 4

    Click the file that matches your platform (see the table below).
