PhotoCraft for Windows

Available architectures: x64, arm64 and x86. Check Settings → System → About → System type before selecting a file.

photocraft-0.6.0-windows-x64.msi

photocraft-0.6.0-windows-x64-portable.zip

For ARM64 or 32-bit x86, choose the matching MSI or portable ZIP from the release Assets list.

  1. Download the matching MSI and run the installer.
  2. Follow the installer prompts, then open PhotoCraft.
  3. For the portable ZIP, extract the whole archive into a folder before starting the app inside it.

PhotoCraft for Linux

x86_64 and aarch64 builds are available as AppImage, DEB, RPM, Flatpak and tar.gz. Select your architecture and distribution format.

photocraft-0.6.0-linux-x86_64.AppImage

Use DEB for a compatible Debian/Ubuntu system or RPM for a compatible RPM-based system. Check upstream requirements and dependencies before installing.

An AppImage may require executable permission and runtime support from your distribution. This page does not present untested Linux installation commands as verified.

PhotoCraft Download FAQ

Is this a paid download?

The linked PhotoCraft release assets are available from the open-source project without a purchase on this site.

Which Windows package should I choose?

Match x64, arm64 or x86 to your system. Use MSI for installation or ZIP for a portable folder. Do not select an architecture only because it appears first.

Does the desktop version fix every browser problem?

No. It can avoid browser-specific limitations, but file compatibility and app issues still need testing. Loading and browser help
