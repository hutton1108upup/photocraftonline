PhotoCraft for Mac

One Universal DMG for Apple Silicon and Intel. Select the desktop DMG, not the separate command-line ZIP.

Download Universal DMG

photocraft-0.8.2-macos-universal.dmg

  1. Save the file ending in -macos-universal.dmg, then double-click it in Finder → Downloads.
  2. Drag PhotoCraft into Applications and wait for copying to finish. Eject the disk image.
  3. In Finder → Applications, double-click PhotoCraft and confirm Open if macOS asks about the downloaded app.

Success check: the PhotoCraft window opens. Choose File → Open, select a sample image and confirm it appears on the canvas.

If macOS reports an unverified developer, check the release source and publisher first. For that specific message, System Settings → Privacy & Security may show Open Anyway. If the message says the app is damaged or contains malware, stop and consult the upstream project instead of bypassing the warning.

PhotoCraft for Linux

Open a terminal and run uname -m. x86_64 means 64-bit Intel/AMD; aarch64 means ARM64. Choose AppImage for a standalone file, DEB for Debian/Ubuntu, RPM for Fedora/RHEL/openSUSE, or a Flatpak bundle if you use Flatpak.

uname -m

The examples below use the checked v0.8.2 files. In your file manager, open the folder containing the downloaded file and choose Open in Terminal. Run only the commands for your chosen format; if a command fails, stop and read the error before continuing.

Installer, CLI, Web ZIP or Source Code ZIP?

  • Desktop installers or portable packages run the graphical editor; match system and architecture first.
  • CLI packages are for terminal conversion and automation. A file named cli is not the graphical desktop app.
  • The photocraft-web ZIP is for self-hosting a WebAssembly website and needs a web server.
  • GitHub Source code ZIP contains source to compile, not an installer to double-click.

PhotoCraft Download FAQ

Is PhotoCraft free to download?

The linked PhotoCraft packages are provided by the free, open-source upstream project. You do not need to make a purchase or create an account on this site.

Is every ZIP a portable application?

No. Choose the Windows ZIP with portable in its filename. Source code archives are for developers, and the web ZIP is a website build for self-hosting.

What if I do not know my architecture?

Use Windows System type or uname -m on Linux. Mac uses the same Universal DMG for both Intel and Apple Silicon. Do not use system detection on this page as proof of processor architecture.

Does the desktop version fix every browser problem?

It can avoid browser-specific limitations, but app and file compatibility still need testing. Loading & Browser Help

For Developers: Web Build & Self-hosting

The photocraft-web ZIP is for hosting the browser version, not installing a desktop app. Find it in the release Assets and follow the upstream hosting documentation.
