What is WordCraft by ArtCraft?

WordCraft is ArtCraft’s open-source word processor implemented in Rust. Upstream describes a Microsoft Word-style ribbon with styles, tables, review tools and document references, plus DOCX reading/writing and PDF export. It is a separate project, not Microsoft Word or a Microsoft-operated service.

The name WordCraft also appears in writing tools, research projects and word games. For wordcraft download or wordcraft github, identify this editor using storytold/wordcraft and getartcraft.com/apps/wordcraft. A same-name product does not establish the same developer or features.

Install or run WordCraft

  1. Download the matching file and read SHA256SUMS.txt from the same release. In PowerShell in the download folder, use the command below with your actual filename; the result must match that exact asset.
  2. Windows portable: right-click the ZIP → Extract All, enter the extracted subfolder and run wordcraft.exe. Keep companion files together. Alternatively run the matching MSI and follow its prompts.
  3. macOS: open the Universal DMG, copy WordCraft into Applications and open it from there. Read the publisher information in any system prompt.
  4. Linux AppImage: open a terminal in its folder, grant executable permission and run it with the commands below. For another package format, follow that release’s distribution instructions.
Get-FileHash ".\wordcraft-0.8.0-windows-x64-portable.zip" -Algorithm SHA256
chmod +x wordcraft-0.8.0-linux-x86_64.AppImage
./wordcraft-0.8.0-linux-x86_64.AppImage

Success check: the WordCraft window opens and you can open a small DOCX file. These are documented installation paths; this page does not certify startup on every machine. If a step fails, stop there and use upstream troubleshooting for the exact error.

A first WordCraft DOCX editing workflow

  1. Open a new document or a copy of a simple DOCX with File → Open. Start with a title, a short paragraph and a small table rather than a complex client document.
  2. Use the Home ribbon’s styles for a heading and normal text. Inspect your actual Chinese font and line spacing; a Chinese menu is not proof of identical Word pagination.
  3. Save As a new DOCX filename, close and reopen that copy. Check text, styles, table cells and pictures. Keep the original file.
  4. Use the File tab’s PDF export. Open the exported PDF and inspect page count, Chinese glyphs, selectable text and clipping. Keep DOCX as the editable master.
  5. If the recipient uses Microsoft Word, open the saved DOCX there before relying on the exchange. DOCX-to-PDF export alone does not test Word compatibility.

This is a beginner checklist based on the upstream workflow, not a desktop GUI test. The CLI-only sample above has a narrower, explicitly checked scope.

WordCraft questions

Is WordCraft free?

The upstream project is open source under MIT / Apache-2.0. This guide links to its public releases. That does not establish free access to every ArtCraft AI or third-party hosting service.

Can I use WordCraft online here?

No. This site currently hosts PhotoCraft and CADCraft, and provides this WordCraft guide. The upstream Web ZIP can be hosted separately; it is not a ready-to-open official trial link.

Will my DOCX look exactly like Microsoft Word?

Do not assume identical pagination, fonts or object preservation. Test a copy in both applications and inspect the PDF you will deliver.

Does a Chinese interface mean full Chinese document support?

Menu translation, input, font shaping, page layout and export are separate checks. Verify them with your own sample.
