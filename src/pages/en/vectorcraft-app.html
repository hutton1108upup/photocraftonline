What Is the VectorCraft App?

VectorCraft is the open-source vector illustration tool in ArtCraft’s lineup, with source at storytold/vectorcraft. Upstream describes paths, shapes, artboards and SVG/PDF workflows. This is an independent product and download guide; this website hosts PhotoCraft and CADCraft, and does not offer a VectorCraft online editor.

App does not necessarily mean a phone app. The checked v0.9.0 release provides desktop packages and a WebAssembly ZIP. Identify the developer and official release before treating a same-name mobile product as this project.

VectorCraft Downloads: Standalone or Launcher

The standalone version checked October 12, 2026 is v0.9.0. Choose a standalone package for only VectorCraft, or examine the official Launcher to manage several Craft apps. They release independently and do not share one version or checksum.

  1. Check the target computer’s system and processor. On Windows use Settings → System → About; on Linux run uname -m; Mac’s Universal DMG serves Apple Silicon and Intel.
  2. Choose a matching installer or portable package from the product page or v0.9.0 release. Do not assume the x64 default fits ARM64 or x86.
  3. Read SHA256SUMS.txt from that same release and verify the exact filename. Extract portable packages completely.
  4. Check importing, editing, native saving, reopening and export with a project copy. We have not tested GUI installation or cross-platform startup.

GitHub VectorCraft: Source, Licenses and Issues

For github vectorcraft or vectorcraft github searches, use storytold/vectorcraft. Source, compiled releases and issue reports serve different purposes. Source code ZIP is not a ready-to-install application.

  • Source repository and README
  • Releases: compiled packages
  • Issues: search first, then include version and reproduction steps
  • MIT / Apache-2.0: read licenses and third-party notices before redistribution.

For source builds, follow the target version’s README and toolchain configuration. Our CLI check uses a published binary, not a source build.

What Did We Actually Test?

On October 12, 2026, the VectorCraft v0.9.0 Windows x64 portable package matched its SHA256. On Windows 11 x64, its vectorcraft-cli.exe saved our original 640 × 400 SVG as .vectorcraft, then exported PNG and SVG from that native document. Document info reported one artboard, four paths and no import warnings. PNG dimensions and four sampled colors were correct.

Repeat the CLI sample: fully extract the official x64 portable package, download our SVG, then run these commands in a terminal in that folder. Use your own input path and stop if a step fails.

.\vectorcraft-cli.exe convert practice-shapes.svg practice-shapes.vectorcraft
.\vectorcraft-cli.exe info practice-shapes.vectorcraft
.\vectorcraft-cli.exe convert practice-shapes.vectorcraft practice-shapes.png
.\vectorcraft-cli.exe convert practice-shapes.vectorcraft practice-shapes-roundtrip.svg

Keep input and output filenames different. Expected native info is 640 × 400, one artboard and four paths, with a 640 × 400 PNG. These commands check only the simple CLI workflow.

VectorCraft App FAQ

Is VectorCraft an Adobe product?

No. It is a separate open-source project. Upstream describes an Illustrator-like workflow; that does not establish complete feature parity.

Can I open VectorCraft on this website?

This site hosts PhotoCraft and CADCraft. Use an official VectorCraft desktop release or follow upstream Web hosting instructions.

Does open source mean every ArtCraft service is free?

This page covers the VectorCraft project, not the account, usage or billing terms of ArtCraft AI model services.
