Choose by Task: Photos, Logos, Video, RAW or Interface Design

Start with PhotoCraft for pixel edits and layered compositions, VectorCraft for paths and scalable logos, FilmCraft for video editing, LightCraft for photo libraries and RAW development, or FigCraft for interfaces and prototypes. The comparisons below explain where the tasks differ.

PhotoCraft and VectorCraft

Examine PhotoCraft for images and pixel layers, or VectorCraft for path-based illustration and scalable shapes. Start with the delivery format; being related apps does not guarantee a compatible file round trip.

PhotoCraft and FilmCraft

Editing a still image and cutting video on a timeline are different jobs. FilmCraft is positioned as a video editor. This site does not provide a FilmCraft online editor.

PhotoCraft and LightCraft

Consider LightCraft for photo libraries and RAW development, then assess PhotoCraft if you need layered compositing. Library work, RAW processing and pixel editing need separate workflow checks.

VectorCraft and FigCraft

Examine VectorCraft for illustrations and paths, or FigCraft’s official product and downloads for screen layouts, components and prototypes. Check the features and formats your deliverable needs.

Web Builds and Source ZIPs Are Different Downloads

An upstream Web ZIP is a WebAssembly app to host according to that project’s instructions; a source ZIP is code to build. Neither is a desktop installer. Choose a desktop package for your operating system and processor.

For a browser image-editing trial, open our hosted PhotoCraft editor. For a desktop app, use the PhotoCraft download guide. Find other Crafting Apps through the matching official product pages in the table above.

Crafting Apps FAQ

Are Crafting Apps free to use?

The official directory describes this app family as free and open source. Check each repository’s license and third-party asset terms separately. ArtCraft AI creation services have their own access and billing terms.

Can I use every Crafting App online?

Not all of them. The current directory lists FilmCraft for macOS, Windows and Linux; the other apps list Web as well. A Web build is not necessarily a hosted editor. This site hosts only PhotoCraft and CADCraft.

Can Crafting Apps fully replace Adobe?

Check the task and files you need to deliver. Several apps are still early alpha or in development. A familiar interface or similar purpose does not establish complete feature, plugin or file-format compatibility.

Are ArtCraft and PhotoCraft the same app?

PhotoCraft is the lineup’s image editor; ArtCraft also has a distinct AI creation product. Use the official app page and repository to identify each.

Does downloading PhotoCraft install the whole suite?

Do not assume that. The PhotoCraft release assets linked here are packages for that editor.

How does getartcraft relate to this website?

getartcraft.com is the upstream official site. This is an independent browser-editor and guide website.

After identifying ArtCraft and PhotoCraft, use the app and version guide, downloads or our hosted editor.
