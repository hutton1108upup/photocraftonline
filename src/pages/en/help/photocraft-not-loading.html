PhotoCraft Not Loading or Working Online?

Start with the symptom you can see. These checks help identify the cause; they cannot guarantee that every browser or file will work.

Tested October 10, 2026: the PNG tutorial succeeded in desktop Chrome. We also tested the site’s missing-WebGPU message and a blocked WebAssembly request. Mac, Linux and mobile hardware were not tested.

1. Check Your Browser and Graphics Support

  1. Use an updated desktop Chrome or Edge and open the editor again. A phone browser may not provide the same controls or GPU support.
  2. In Chrome, open Settings → System and check “Use graphics acceleration when available.” In Edge, search Settings for “graphics acceleration.” If you change it, restart the browser.
  3. If this site says WebGPU is unavailable, try another supported desktop browser or the desktop app. Do not disable browser security or use experimental flags as a general fix.

2. When the Editor Stops Loading

  1. Allow time for the first download. The current WebAssembly file is about 25 MB; network speed affects startup.
  2. If a retry prompt appears before you have opened a document, choose Retry editor. Reloading discards any unsaved editor work.
  3. Open Developer Tools → Network, reload, and look for a failed .wasm or photocraft-web-…js request. An HTTP error or blocked request is a loading issue, not evidence that your image is corrupt.
  4. If the file requests succeed but startup still stalls, try a fresh browser tab and a different supported browser. Record the visible error before reporting it.

3. When a File Will Not Open

First open the small PNG used in our tutorial. If it works, test a copy of your original file. A complex PSD or large image can fail for different reasons than editor startup.

Keep backups, reduce file size where practical, and avoid uploading confidential documents to a public issue tracker. We have not validated every supported format or every PSD feature.

4. Try the Desktop Version

If browser graphics support is the blocker, the native app uses a different environment. Choose the correct OS and architecture from the official release. A desktop download is an alternative to test, not a guarantee that a file problem will disappear.

5. Report a PhotoCraft Problem

For an editor-engine problem, search existing issues first, then include your OS, browser version, hosted build ID, steps to reproduce and a screenshot without private content. This site is independent of the upstream team.
