1. Start PhotoCraft Online

Open the editor, wait until the welcome screen appears, and choose a desktop browser with working graphics support. The initial download includes about 25 MB of WebAssembly.

2. Open Your First Image

For this exercise, download our original practice image, then choose Open… in the welcome screen (or File → Open…) and select practice-image.png. You can also drag the file onto the canvas.

Download the practice PNG

3. Understand the Workspace

  • Top: File, Edit, Image and Layer menus, followed by tool options.
  • Left: the toolbar, including the Brush tool.
  • Center: your image canvas.
  • Right: colors, properties and the Layers panel.

4. Make a Basic Edit with Layers

  1. Select Background in Layers. On Windows/Linux press Ctrl + J; on Mac use ⌘ + J. A new Background copy appears.
  2. Keep the copy selected. Click the Brush tool in the left toolbar. Use the foreground color swatch to choose your color.
  3. Drag across the blank lower area of the practice image to draw a short line. Our screenshot uses the default black brush.
  4. If needed, choose Edit → Undo. The original Background layer remains under the copy.

5. Export Your Finished Image

  1. Choose File → Export → Quick Export as PNG.
  2. Check your browser Downloads list. If a save dialog appears, choose a folder and save under a new filename.
  3. Open the downloaded PNG and confirm the brush stroke appears. PNG is a flattened image; it does not preserve your editable layers.

We verified the PNG edit and the simple two-layer PSD save and reopen below. More basic text and mask samples are documented below; complex PSDs, arbitrary fonts and professional workflows still need separate tests.

6. Save Layers So You Can Edit Again

The exported PNG is a flattened image. Save a separate editable document if you want to keep working with layers.

  1. Keep the two-layer practice document open and choose File → Save As…. Our browser test downloaded practice-image.psd.
  2. Find the PSD in your browser Downloads list and confirm it is stored on your computer.
  3. Choose File → Open… and reopen the PSD. Check that Layers still contains Background copy and Background, and that the brush edit remains visible.
  4. Keep the PSD for editing; export a separate PNG for the flattened result.

This is a simple check of our build, not a Photoshop round-trip test or a guarantee for text, smart objects, masks or other PSD effects.

7. More Useful Edits: Checked Browser Examples

These additional samples were run on October 14, 2026 in Windows desktop Chrome, using the same pinned Web build. Start each exercise with a fresh copy of the practice PNG. Export and inspect the result before closing the editor.

Resize an image

  1. Choose Image → Image Size… .
  2. Set Width to 320 and Height to 200 pixels. Keep Resample selected, then choose OK.
  3. Quick Export as PNG and inspect the downloaded dimensions. Our output is 320 × 200.

Crop to a selected region

  1. Choose the Crop tool in the left toolbar. Drag a rectangle over the part you want to keep.
  2. Confirm using the checkmark at the top right, then export a PNG. Our selected region exported at 300 × 200.

Add a short text layer

  1. Click the T / Type tool, then click an empty area of the canvas.
  2. Type Hello PhotoCraft. This sample uses the default Inter type controls. Confirm using the top checkmark.
  3. Export PNG and inspect the text. A simple rendered text sample is tested; arbitrary fonts, typography and PSD text editability are not established.

Create and export a transparent PNG

  1. Choose File → New… . Set Width to 320 and Height to 200 pixels.
  2. Under Background Contents, choose Transparent, then Create.
  3. Draw a short brush stroke and export PNG. The checked RGBA output contains alpha values from 0 to 255, preserving transparent and opaque areas.

Hide a copied-layer edit with a simple mask

  1. Repeat the layer exercise: duplicate Background and draw a black line on the copy.
  2. Select the copy. At the bottom of Layers, click Add layer mask, shown as a rectangle with a circle. A white mask thumbnail appears.
  3. Click the white mask thumbnail, select the Brush tool and black foreground, then paint over the line. The original layer below becomes visible there.
  4. Export PNG. Our sampled pixel changed from the black edit RGB(0, 0, 0) to the original green RGB(22, 78, 71). PNG flattens the result; it does not keep editable masks.

What to Check When You Cannot Find the Export

  1. Confirm a document is open and the canvas shows your intended edit, then choose File → Export → Quick Export as PNG.
  2. Check the browser Downloads list and downloads folder for a failed or blocked entry. Repeated downloads may have a numbered filename.
  3. If the browser asks for download permission or a save location, follow that specific prompt. Keep the editor tab open until the file is saved.
  4. If a file exists but looks wrong, reopen the PNG, check layer visibility and export again. Keep your original if the task still fails, then consult loading help or alternative editors.

This site does not provide a dependable automatic backup. Keep your original, PSD and exported image yourself. File handling and safety checks.

Common Beginner Questions

Can I use my own image?

Yes. Try a small PNG first and keep the original. Large images and complex PSD documents may need more memory or behave differently.

Will this work on my phone?

The interface is designed for desktop use. For this tutorial, use a computer with a keyboard and mouse. Browser graphics support varies.
