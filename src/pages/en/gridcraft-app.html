What is GridCraft by ArtCraft?

GridCraft is ArtCraft’s open-source spreadsheet implemented in Rust, with an Excel-style ribbon, formula bar and sheet tabs. Upstream documents XLSX workbooks, CSV/TSV exchange, calculation functions, tables, charts and PivotTables. It is a separate project, not Microsoft Excel.

GridCraft is also used for unrelated game hosting, pixel-art and other products. For gridcraft download or gridcraft github, check storytold/gridcraft and getartcraft.com/apps/gridcraft before choosing a file or following a tutorial.

Install or run GridCraft

  1. Download the matching file and read SHA256SUMS.txt from the same release. In PowerShell in the download folder, use the command below with your actual filename; the result must match that exact asset.
  2. Windows portable: right-click the ZIP → Extract All, enter the extracted subfolder and run gridcraft.exe. Keep companion files together. Alternatively run the matching MSI and follow its prompts.
  3. macOS: open the Universal DMG, copy GridCraft into Applications and open it from there. Read the publisher information in any system prompt.
  4. Linux AppImage: open a terminal in its folder, grant executable permission and run it with the commands below. For another package format, follow that release’s distribution instructions.
Get-FileHash ".\gridcraft-0.6.1-windows-x64-portable.zip" -Algorithm SHA256
chmod +x gridcraft-0.6.1-linux-x86_64.AppImage
./gridcraft-0.6.1-linux-x86_64.AppImage

Success check: the GridCraft window opens and you can open a small XLSX file. These are documented installation paths; this page does not certify startup on every machine. If a step fails, stop there and use upstream troubleshooting for the exact error.

A first GridCraft workbook and formula check

  1. Create a blank workbook or open a copy of a small XLSX. Enter the two-row example below so you know the expected values.
  2. Put quantity in column B, price in C and a multiplication formula in D. Enter =B2*C2 in D2, =B3*C3 in D3 and =SUM(D2:D3) in D4.
  3. Check the expected results: 70, 60 and total 130. Change B2 from 2 to 4; D2 should become 140 and the total 200. This tests whether dependent formulas recalculate.
  4. Save under a new XLSX filename, close and reopen it. Confirm cell formulas as well as displayed values; a cached value alone does not prove recalculation.
  5. Before exchanging it with an Excel user, open the saved copy in their required Excel version and inspect formulas, formatting and charts.

GridCraft XLSX and CSV: preserve the right information

Workbook and data formats
FormatIntended useCheck before saving
XLSXMain workbook format with formulas, sheets and formatting.Formula recalculation, sheets, charts, validation and reopening in the recipient’s app.
CSV / TSVDelimited text for data exchange, not a full workbook.UTF-8 Chinese text, delimiter, dates, leading zeros and numeric precision.
XLS / XLSB / ODSLegacy or alternate formats require their own import checks.Do not infer full editable-format parity from an XLSX feature list or imported values.
XLSMMacro-enabled Excel workbook; not an ordinary XLSX.Upstream reports VBA is dropped on import with a warning. Do not use it to preserve a macro workbook.

For CSV to XLSX, import a copy, inspect identifiers such as 00123, Chinese headers and dates, then save to XLSX and reopen. CSV does not carry the workbook’s charts, multiple sheets and formatting. Microsoft format-loss explanation.

GridCraft questions

Is GridCraft free?

The upstream project is open source under MIT / Apache-2.0. This guide links to its public releases. That does not establish free access to every ArtCraft AI or third-party hosting service.

Can I use GridCraft online here?

No. This site currently hosts PhotoCraft and CADCraft, and provides this GridCraft guide. The upstream Web ZIP can be hosted separately; it is not a ready-to-open official trial link.

Will my Excel workbook and macros still work?

Do not assume that. Test formulas and saved structures; the tagged upstream assessment explicitly reports VBA limitations.

Does a Chinese interface mean full Chinese document support?

Menu translation, input, font shaping, page layout and export are separate checks. Verify them with your own sample.
