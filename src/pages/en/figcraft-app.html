What is FigCraft? Identify the ArtCraft project

This guide covers storytold/figcraft, the ArtCraft team’s free, open-source interface design and prototyping app written in Rust under MIT / Apache-2.0 licenses. It follows a familiar Figma-style workflow and is an independent project, unaffiliated with Figma.

The same name also appears on an AI image/video product and a Figma MCP plugin. Check the repository owner storytold and getartcraft.com/apps/figcraft before downloading. This website is an independent guide, not the official FigCraft site.

Install and check the first launch

  1. Download the file matching your OS and architecture, plus SHA256SUMS.txt from the same release.
  2. Windows: run the MSI, or right-click the ZIP → Extract All, keep the complete folder and run figcraft.exe. macOS: open the DMG and copy the app to Applications. Linux: follow the selected package format; an AppImage needs executable permission.
  3. Start with a small new design. Save it under a new name, close and reopen it, then inspect text, layers and positions.

For example, open PowerShell in your Windows download folder and check the x64 portable package:

Get-FileHash .igcraft-0.6.0-windows-x64-portable.zip -Algorithm SHA256

The hash must exactly match the same asset in SHA256SUMS.txt. These steps follow upstream packaging; we have not tested the installer or desktop UI here. If a step fails, stop there and search upstream Issues with your version, OS and error.

FigCraft online: browser use or a Web ZIP?

Upstream publishes a WebAssembly build for browser hosting. A Web ZIP contains files to serve as a website; it is neither a desktop installer nor an already-running editor. This site does not host a FigCraft editor. The header’s “Open free editor” button opens the PhotoCraft image editor.

Before using a third-party FigCraft online site, check its hosted version, file handling and actual features. Desktop documentation does not establish identical browser imports, local font access or document saving.

Getting started: make and save a small screen

  1. Create a frame and add a heading, a button shape and supporting text.
  2. Apply auto layout to the content that should flow together. Adjust gap, padding and width, then lengthen the text to inspect wrapping and overflow.
  3. Turn a repeated button into a component and instance. Edit the main component and check its instances.
  4. Add a second frame, connect a prototype interaction and preview the navigation.
  5. Save a native .figcraft document and reopen it, then export an image and inspect the result.

This is a documentation-based practice sequence, not a completed hands-on screenshot tutorial. Check your tasks with a practice file before migrating an original project.

Can it replace Figma? Check the limits first

FigCraft remains alpha software. Its .fig import is best effort, not a guarantee that every font, component or prototype survives. Live collaboration is a preview, and its plugins use its own WebAssembly system; that does not make Figma plugins directly compatible.

Upstream describes local offline use without an account or telemetry. Sharing or joining files introduces network connections. Online sharing sends the document to the selected server, so “files never leave your computer” would be too broad.

FigCraft FAQ

Is FigCraft free?

The ArtCraft FigCraft project covered here is free and open source; do not confuse it with paid services using the same name.

Is FigCraft a Figma plugin?

storytold/figcraft is a standalone design app. The same-name Figma MCP plugin is a different project.

Can FigCraft open Figma files?

Upstream documents best-effort .fig import. Keep the original and inspect text, layout and components in a copy. A Figma web link is not the same input as a local .fig file.
