Is PhotoCraft Open Source?

The upstream PhotoCraft repository publishes Rust source and lists MIT and Apache-2.0 licenses. Read the actual MIT license and Apache-2.0 license, plus the project’s notices, before reusing or distributing code.

Open source describes source availability and licensing. It does not certify compatibility, security, the behavior of every binary, or the policies of a website that hosts a build. Our static website wrapper and the upstream editor are separate projects. Source and safety checks.

How FreePhotoCraft.online Relates to the Project

ArtCraft’s project page is getartcraft.com/apps/photocraft. The upstream repository maintains the editor source, releases and engine issue tracker.

FreePhotoCraft.online independently hosts an unchanged WebAssembly engine binary and provides navigation, loading feedback and bilingual guides. We do not own PhotoCraft and are not operated, endorsed or sponsored by the upstream team. The web engine’s version is fixed until we deliberately update it; it is not automatically the latest desktop version.

Download from GitHub Releases

  1. Open Releases. Choose the version you want; read its notes and system requirements.
  2. Expand Assets. Select the package that matches your system and architecture, rather than downloading the source-code ZIP to install the app.
  3. If provided, download SHA256SUMS.txt from the same release and compare the exact filename’s checksum.

Use our desktop download guide for the checked package filenames and platform steps. Release contents change; this source guide does not invent an installer name for a future version.

GitHub and Open-Source Questions

Is this the official PhotoCraft repository?

The external source links on this page point to storytold/photocraft, the upstream repository. FreePhotoCraft.online is an independent site.

Does the source-code ZIP install PhotoCraft?

No. It contains source files. Use a platform package from the release’s Assets list, or follow the upstream build instructions if you intend to build from source.

Where should I report an editor bug?

Search upstream Issues, then include your build, browser or OS and safe reproduction steps. Keep private files out of public reports.
