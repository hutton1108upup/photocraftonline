Privacy Policy

This notice describes the current website and hosted browser editor. Last updated: October 15, 2026.

Editor Files and Local Processing

The WebAssembly editor runs in your browser. In our local-preview PNG import, layer edit, simple two-layer PSD save and reopen, and PNG export test, we observed no request uploading the image to a server. Our site code does not include an image-upload endpoint. This test does not certify every feature of the upstream editor.

Save important work yourself and keep source backups. Browser storage or an open tab is not a guaranteed backup.

Website Requests and Hosting

When you load the site, the hosting service receives ordinary request information such as IP address, requested URL, time and browser headers to deliver pages and editor assets. The production configuration uses Cloudflare Workers static assets; Cloudflare’s processing is described in its privacy policy. Local preview requests go to the local server instead.

Cookies, Preferences and Analytics

Our site code reads a theme preference from localStorage when present, and otherwise follows your system color scheme. The editor or browser may use local storage for its own settings. You can clear site data in browser settings; doing so may remove saved preferences or editor-local data.

Content pages on the production domain configure Google Analytics 4 to understand page visits and key clicks: opening the editor, jumping to downloads, desktop download links, tutorials, manual system choices, practice-image downloads and screenshot viewing. Google may use cookies, device/browser information and interaction events to produce reports. A download click does not establish a completed download or installation. Google privacy policy.

Our custom event parameters use only fixed entry positions, page types, interface language, system, architecture, file format, release version, tutorial step and screenshot ID. They do not read file contents, personal filenames or input values, and do not include page query strings or fragments. Referrer values retain only the origin. Editor/engine routes, local previews and workers.dev do not load our GA4 tag.

The production site may also use its existing Cloudflare Web Analytics for visits and performance. This change adds no Clarity, advertising tags, session replay or consent popup. Browser cookie, site-data and blocking controls can manage related behavior.

Accounts, Payments and External Services

This site has no account registration, checkout, subscription or payment-data collection. GitHub downloads, Adobe, ArtCraft and community links leave this site and follow their own policies. Information you post to an external issue tracker or community is handled by that service; do not include confidential files.

Scope and Changes

FreePhotoCraft.online is independent of ArtCraft. If hosting, analytics or file handling changes, this page must be updated to describe the actual behavior. Upstream editor issues belong on its issue tracker; that tracker is not a private inbox for this website.
