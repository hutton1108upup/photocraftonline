What Does “AI Photoshop Clone” Mean Here?

AI-assisted development, agent-controlled editing and generative image tools are different things. PhotoCraft is an open-source Photoshop-style editor; the pinned browser build on this site has no connected AI assistant or generative model service.

Upstream documents command automation and MCP, but its v0.8.2 README lists AI/generative features among gaps. This page’s AI keyword does not add those capabilities to the hosted engine.

Questions Before You Start Editing

Is this online editor free?

Yes. The hosted editor and the illustrated practice workflows require no payment, site account or desktop installation.

Does AI Photoshop Clone include Generative Fill?

No. This hosted build has no connected AI assistant, text-to-image model or Generative Fill service. Here the term leads to a Photoshop-style PhotoCraft editor, not an AI generation promise.

Can I save a PSD and continue editing?

A simple two-pixel-layer PSD was saved and reopened in our pinned Web build, then exported to PNG with the edit retained. Complex PSDs, fonts, smart objects and Photoshop round trips still need separate checks.

Which browser should I use?

These examples were tested in desktop Chrome on Windows. Use an updated desktop browser with working graphics support. This is not a compatibility test of every browser, phone or operating system.

What happens to my image files?

The hosted engine runs in the browser. No image upload was observed in the documented local sample workflows. Website hosting and analytics requests are separate; read the privacy and safety pages for their actual scope.

Can I work offline?

The online editor needs its files downloaded before it can start. We have not verified persistent offline startup or a service-worker cache. For offline use, examine the official desktop app and test your workflow.

Why can’t I find the exported image?

Use File → Export → Quick Export as PNG, then check the browser Downloads list and any save or permission prompt. Keep the tab open until the file is saved. Loading and export troubleshooting are linked below.

Is this Adobe Photoshop or an official ArtCraft site?

No. PhotoCraft is an independent open-source editor, and this website is independent of Adobe and ArtCraft.
