What is CADCraft?

CADCraft is ArtCraft’s open-source drafting app, implemented in Rust with an AutoCAD-style command-line workflow. It handles technical drawings rather than pixel photo editing. For cadcraft app or cadcraft github searches, identify the project by the storytold/cadcraft repository; similar names in training services or other apps do not establish the same developer.

Upstream labels it early development. Start with a simple copy of a drawing and verify the output before replacing an existing CAD workflow. Compare CADCraft and AutoCAD。

Install or run CADCraft

  1. Download from the official release, and compare Get-FileHash FILE -Algorithm SHA256 with the same release’s SHA256SUMS.txt. Replace FILE with the downloaded file path.
  2. Windows portable: right-click the ZIP → Extract All, open the extracted folder and run cadcraft.exe. An MSI is an alternative installed application; our check used the portable build.
  3. Mac: open the Universal DMG and copy the app into Applications. Linux AppImage: in its folder run chmod +x cadcraft-0.6.2-linux-x86_64.AppImage, then ./cadcraft-0.6.2-linux-x86_64.AppImage. These platform steps follow upstream packages; Mac and Linux startup were not tested here.
  4. Success check: the drafting window opens, and File → Open displays our sample DXF. Keep the original drawing unchanged.

Interface language: Edit → Interface Language. Simplified Chinese is listed in the v0.6.2 README and appeared in our Windows screenshots. Display depends on available CJK fonts.

Our downloaded Windows x64 portable ZIP and Web ZIP matched the official SHA256SUMS. That is a file-integrity check, not a guarantee for every drawing or device.

DXF, DWG and compatibility limits

The tagged README describes DXF and DWG reading/writing, SVG/PNG export and PDF plotting. Our Windows check retained a rectangle, two circles and one dimension after DXF save/reopen and after CADCraft’s own DWG conversion/reopen. It did not test those files in AutoCAD. Our browser check covered DXF only.

Unsupported entities can be lost on save. SHX fonts, advanced 3D, custom objects, external references and complex plotting need separate checks. Do not overwrite a production drawing to test compatibility. Format support。

CADCraft questions

Do I need Rust to use CADCraft?

No for a compiled desktop package or the browser app. Rust is for building the source.

Is this an official CADCraft online app?

No. We independently host the unchanged official v0.6.2 Web build. The official Web ZIP is a self-hosting package, not a public official trial URL.
