Is PhotoCraft an Adobe Product?

No. PhotoCraft’s upstream project is storytold/photocraft and describes a familiar Photoshop-style workflow. Similar interfaces, shortcuts and PSD support do not make it an Adobe-developed product or establish complete feature parity. This site is also independent of Adobe and ArtCraft.

Layers, PSD Files and Current Limits

For a first PNG edit, you can try PhotoCraft with a duplicate layer and a brush stroke. For a complex PSD, compare a copy against the original before relying on the output. Do not assume every font, layer style, linked object or plugin effect survives a browser round trip.

A native PhotoCraft release can have different features from this hosted WebAssembly build. We do not promise complete Photoshop replacement, AI-feature parity, or faster performance.

Use the Migration Checklist

How to Compare Your Own Files Before Switching

  1. Copy a representative document and record dimensions, fonts, layers, masks, transparent areas and required plugins.
  2. Open a copy in each exact version you plan to use. Make the same edit, save an editable document and export a PNG from each.
  3. Reopen the saved documents and inspect layer structure and editability. Compare PNG text wrapping, edges, colors and transparent regions side by side.
  4. Record differences as workflow limits. Keep your existing process if a required element fails, or examine other alternatives.

This is a method for you to run, not a Photoshop test already performed by this site.

PhotoCraft vs Photoshop Questions

Can PhotoCraft fully replace Photoshop?

This check cannot establish that. The small layer exercise works; professional documents and delivery workflows need separate validation.

Does the PSD result prove complex documents are compatible?

No. It checks two pixel layers saved and reopened within PhotoCraft, without Photoshop or complex effects.

Should I use the browser or desktop app?

The browser is a quick starting point. Examine upstream releases if you need a desktop environment, but their features and requirements can differ. Desktop downloads.
