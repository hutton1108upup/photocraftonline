About FreePhotoCraft.online

Independent browser access and practical guides for the open-source PhotoCraft editor. Updated October 10, 2026.

What Is This Site?

FreePhotoCraft.online is an independent website. It is not operated by, affiliated with, endorsed by or sponsored by ArtCraft or the PhotoCraft development team.

We provide a free browser editor, a tested beginner tutorial, download guidance, a Photoshop comparison and browser-loading help. We do not offer site accounts, paid subscriptions or a checkout.

The Hosted Editor Build

The editor loads the local WebAssembly build 72921900975c7e6f from /editor-app/. Its engine binaries are unchanged. Our wrapper adds loading feedback, retry, tutorial and help links without replacing the engine.

This build is not automatically updated to match the latest desktop release. On October 10, 2026 we tested PNG import, layer duplication, a brush edit and PNG export in desktop Chrome. We did not certify every PSD feature or every operating system.
