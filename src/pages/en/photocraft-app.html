What Is the PhotoCraft App?

This page covers the open-source PhotoCraft image editor in ArtCraft’s lineup, with upstream source at storytold/photocraft. Its official description includes layers, masks, adjustments, type, brushes and PSD workflows, and labels the project early alpha.

“App” does not necessarily mean a mobile application. This project publishes desktop packages and a Web build; this website’s main entry point is the hosted browser version. ArtCraft and PhotoCraft explained。

How to Start Using PhotoCraft Software

Try the browser first

  1. Open our free editor and wait for the welcome screen.
  2. Download the original practice PNG and follow the tutorial to open it, duplicate a layer, edit and export.
  3. Reopen the output to check it. Keep an editable document and a flattened image separately if you want to continue working with layers.

Use a desktop package

  1. Open the platform download guide; Windows users can go directly to the Windows guide.
  2. Check architecture, release, source and checksum, then follow the platform’s installation or portable steps.
  3. Verify opening, editing, saving and reopening a copy before using important work.

Is a PhotoCraft App-Store Listing the Same Product?

Do not identify a product by its name alone. The checked upstream release lists desktop and Web assets, not an Android APK or iOS package. Google Play also lists PhotoCraft AI: Edit & Art by 89 games, with a developer identity different from this upstream project. View that store listing。

  • Check whether the developer, official site, repository and privacy notice identify the same product.
  • Do not use our desktop/Web tutorial as instructions for another mobile app.
  • Our editing interface is primarily for desktop browsers. Reading a guide on a phone does not establish a tested mobile editing workflow.

What Has Been Tested on This Site?

The pinned Web build was checked for PNG import, layer duplication, a brush edit, a simple two-layer PSD save and reopen, and PNG export. Complex PSDs, type, masks, transparency, a Photoshop comparison and every professional workflow have not been validated.

Is the PhotoCraft app an Adobe product?

No. This page covers a separate upstream open-source project, without an Adobe-product or complete Photoshop-replacement claim.

Must I install it before using it?

No desktop installation is required for our browser version, but your first visit still downloads the editor assets.

Are all mobile, desktop and Web products with this name one app?

Do not assume that. Check the developer, release files and actual build.
