PhotoCraft app 是什么软件？

本页介绍 ArtCraft 的 Crafting Apps 家族中的开源 PhotoCraft 图片编辑器，上游仓库为 storytold/photocraft。官方介绍了图层、蒙版、调整、文字、笔刷和 PSD 等工作流，并标注项目为早期版本。

“app”不一定指手机应用。这个项目发布桌面程序和 Web 构建；本站的核心入口是托管在浏览器中运行的版本。 Crafting Apps 全套工具与用途对比。

怎样开始使用 PhotoCraft 软件？

先在浏览器试用

  1. 打开本站免费编辑器，等待欢迎界面。
  2. 下载原创练习 PNG，跟随教程打开、复制图层、修改并导出。
  3. 重新打开输出，确认结果。需要继续编辑图层时，分别保存可编辑文档与合成图片。

使用桌面程序

  1. 进入系统下载指南；Windows 用户可直接查看Windows 专页。
  2. 核对架构、发布版本、来源和校验值后，按对应平台说明安装或解压运行。
  3. 用一份副本验证打开、编辑、保存和重开完整流程，再处理重要作品。

手机应用商店中的 PhotoCraft 是同一产品吗？

不要仅凭名称认定相同。当前核查的 PhotoCraft 上游资产包含桌面和 Web 文件，没有在该发布中列出 Android APK 或 iOS 安装包。Google Play 也存在由 89 games 发布的同名 PhotoCraft AI: Edit & Art，开发者与上游项目不同。 查看该商店条目。

  • 核对开发者、官网、仓库和隐私说明是否对应同一产品。
  • 不要用本站桌面/Web 教程作为其他手机应用的操作说明。
  • 本站界面主要面向桌面浏览器；手机可以阅读指南，不代表移动编辑流程已经验证。

哪些功能在本站验证过？

固定 Web 构建验证了 PNG 导入、复制图层、笔刷修改、简单两层 PSD 保存与重开和 PNG 导出；复杂 PSD、文字、蒙版、透明背景、Photoshop 对照和全部专业工作流没有完成验证。

桌面 x64 便携包另有有限的 CLI 样例验证，范围见 Windows 页；不能把两种测试合成对所有平台的认证。 Windows 核验范围。
