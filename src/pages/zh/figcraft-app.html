FigCraft 是什么？先确认你找的是哪个项目

这里介绍的是 storytold/figcraft：ArtCraft 团队用 Rust 实现的免费开源界面设计与原型工具，采用 MIT / Apache-2.0 双重许可。它面向熟悉 Figma 工作方式的用户，是独立项目，不隶属于 Figma。

同名产品还包括 AI 图片视频软件和 Figma 内的 MCP 插件。下载前核对仓库所有者 storytold 和 getartcraft.com/apps/figcraft。本站提供独立指南，不是官方 FigCraft 网站。

安装前后怎么检查

  1. 下载与电脑系统、架构匹配的文件，并取得同一发行版的 SHA256SUMS.txt。
  2. Windows：运行 MSI，或右键 ZIP → 全部解压，保留完整文件夹后运行 figcraft.exe。macOS：打开 DMG，把应用复制到 Applications。Linux：按发行包格式安装；AppImage 需先赋予执行权限。
  3. 启动后先创建一个小设计，保存为新文件，关闭后重新打开，确认文字、图层与位置保留。

例如在 Windows 下载目录打开 PowerShell，对 x64 便携包运行：

Get-FileHash ./figcraft-0.6.0-windows-x64-portable.zip -Algorithm SHA256

结果应与同名资产的 SHA256 完全一致。安装说明依据上游发布方式整理；本页没有完成安装器或桌面界面实测。若某一步失败，停在该步，记录版本、系统和错误信息后查询上游 Issues。

FigCraft online：在线使用与 Web ZIP 有什么区别？

上游提供 WebAssembly 构建，可用于浏览器托管。下载 Web ZIP 得到的是网站运行文件，不是桌面安装器，也不是已经打开的编辑器。本站目前没有托管 FigCraft 编辑器；顶部“打开免费编辑器”进入的是 PhotoCraft 图片编辑器。

尝试第三方 FigCraft 在线站时，先核对其托管版本、文件处理方式和实际可用功能。桌面版说明不能直接证明浏览器版也能导入相同文件、访问本地字体或完整保存设计。

第一次使用：做一个小界面并保存

  1. 创建 Frame，加入标题、按钮矩形和说明文字。
  2. 把需要跟随排列的内容放入自动布局，调整间距、内边距与宽度；拉长文字，检查是否换行或溢出。
  3. 把重复按钮做成组件与实例，修改主组件后检查实例。
  4. 增加第二个 Frame 和原型连接，预览跳转。
  5. 保存原生 .figcraft 文档并重新打开，再导出图片，检查结果。

这是一份依据文档整理的练习顺序，不是已完成的图文实测教程。先用练习文件验证自己的任务，再考虑迁移原项目。

能替代 Figma 吗？先看这些限制

FigCraft 仍处于 Alpha；.fig 导入采用尽力兼容方式，不能保证所有文字、组件与原型保留。协作属于预览能力，插件采用自己的 WebAssembly 系统，不能据此认为 Figma 插件可以直接运行。

上游描述本地离线工作无需账号、没有遥测；但分享或加入文件会建立网络连接。在线分享会把文件发送到所选服务器，不能概括为“所有文件永不离开电脑”。

FigCraft、VectorCraft 与 PhotoCraft 怎么选？

做界面、组件和交互原型，先看 FigCraft；做插画与矢量路径，查看 VectorCraft 与 FigCraft 的区别；处理照片与像素图层，查看 PhotoCraft。系列品牌相同不代表文件结构可以无损互通。

FigCraft 常见问题

FigCraft 免费吗？

此处介绍的 ArtCraft FigCraft 是免费开源项目；不要与同名收费服务混淆。

FigCraft 是 Figma 插件吗？

storytold/figcraft 是独立设计应用。同名 Figma MCP 插件是另一个项目。

可以直接打开 Figma 文件吗？

上游描述尽力导入 .fig；保留原文件，用副本核对文字、布局和组件。Figma 网页链接与本地 .fig 文件也不是同一种输入。
