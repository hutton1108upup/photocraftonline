如何使用 PhotoCraft：免费新手教程

1. 打开 PhotoCraft 在线编辑器

打开编辑器，等待欢迎界面出现。建议使用支持图形加速的桌面浏览器；首次加载包含约 25 MB 的 WebAssembly 文件。

2. 打开第一张图片

先下载本站原创练习图，再点击欢迎界面的 Open…，或菜单 File → Open…，选择 practice-image.png。也可以把文件拖到画布上。

下载 PNG 练习图

3. 认识工作区

  • 上方：File、Edit、Image、Layer 等菜单，下方是工具参数。
  • 左侧：工具栏，包括 Brush 笔刷。
  • 中间：图片画布。
  • 右侧：颜色、属性和 Layers 图层面板。

4. 在图层副本上做一次修改

  1. 在 Layers 中选中 Background。Windows/Linux 按 Ctrl + J；Mac 使用 ⌘ + J，生成 Background copy。
  2. 保持副本选中，点击左侧工具栏中的 Brush 笔刷工具。通过前景色方块选择颜色。
  3. 在练习图下方的空白区域拖动鼠标画一条短线；示例使用默认黑色笔刷。
  4. 需要撤销时点击 Edit → Undo。原始 Background 图层仍在副本下方。

5. 导出完成的图片

  1. 点击 File → Export → Quick Export as PNG。
  2. 查看浏览器下载列表。如果弹出保存窗口，选择文件夹，并使用新文件名保存。
  3. 打开下载的 PNG，确认笔刷修改已保留。PNG 是合成图片，不会保留可编辑图层。

本教程验证了 PNG 编辑，以及下方简单两层 PSD 的保存和重开；下方新增了基础文字与简单蒙版样例；复杂 PSD、任意字体及专业工作流仍需单独验证。

6. 保存图层，方便继续编辑

导出的 PNG 是合成图。需要继续调整图层时，另外保存可编辑文档。

  1. 保持练习图中的两层文档打开，点击 File → Save As…。本次浏览器测试下载了 practice-image.psd。
  2. 在浏览器下载列表找到 PSD，确认文件已保存到电脑。
  3. 点击 File → Open… 重新打开该 PSD；检查 Layers 面板中仍有 Background copy 和 Background，并确认笔刷修改仍显示。
  4. 保留 PSD 供继续编辑，另外用 PNG 交付合成图片。

这是本站构建的简单样例，不代表在 Photoshop 中验证过，也不保证文字、智能对象、蒙版或其他 PSD 效果完整保留。

7. 更多实用编辑：浏览器实测小样例

以下小样例于 2026 年 10 月 14 日在 Windows 桌面 Chrome 中运行，使用相同固定 Web 构建。每项练习都从新的练习 PNG 副本开始，导出并检查结果后再关闭编辑器。

缩放图片

  1. 点击 Image → Image Size… 。
  2. 把 Width 设为 320、Height 设为 200 像素，保持 Resample 勾选，点击 OK。
  3. 使用 Quick Export as PNG，核对下载图片尺寸。本站输出为 320 × 200。

裁剪选中区域

  1. 点击左侧 Crop 裁剪工具，拖出要保留区域的矩形。
  2. 点击右上方勾号确认，再导出 PNG。本站选中区域导出为 300 × 200。

增加短文字图层

  1. 点击 T / Type 文字工具，再点击画布空白处。
  2. 输入 Hello PhotoCraft。本样例使用默认 Inter 文字参数，通过顶部勾号确认。
  3. 导出 PNG 并检查文字。已验证简单文字渲染样例，未证明任意字体、排版或 PSD 文字可编辑性。

创建并导出透明 PNG

  1. 点击 File → New…，将 Width 设为 320、Height 设为 200 像素。
  2. 在 Background Contents 中选择 Transparent，再点击 Create。
  3. 画一条短笔刷线，再导出 PNG。核查后的 RGBA 输出含 0 至 255 的 alpha 值，保留了透明和不透明区域。

用简单蒙版隐藏图层副本上的修改

  1. 重复图层练习：复制 Background，在副本上画一条黑线。
  2. 选中副本，在 Layers 面板底部点击 Add layer mask（矩形内带圆形的图标），出现白色蒙版缩略图。
  3. 点击白色蒙版缩略图，选择 Brush 工具和黑色前景色，在黑线处绘制，露出下方原图层。
  4. 导出 PNG。本站采样像素从黑色修改 RGB(0, 0, 0) 恢复为原始绿色 RGB(22, 78, 71)。PNG 会合成结果，不保留可编辑蒙版。

没有找到导出图片时怎么检查？

  1. 先确认已经打开文档，且画布显示预期修改；再点击 File → Export → Quick Export as PNG。
  2. 查看浏览器下载列表与下载文件夹，留意失败或被阻止的提示；重复下载的文件可能带编号。
  3. 如果浏览器提示下载权限或选择保存位置，按具体提示处理。不要在结果未保存前刷新或关闭标签页。
  4. 文件已下载但内容不符时，重新打开 PNG，核对图层可见性并再导出。无法完成时，保留原稿，查看故障帮助或替代工具。

常见新手问题

可以使用自己的图片吗？

可以。建议先用较小的 PNG，并保留原文件。大图和复杂 PSD 可能需要更多内存，表现也可能不同。

手机也能使用吗？

编辑器界面面向桌面操作。跟随本教程时请使用配有键盘和鼠标的电脑；不同浏览器的图形支持有所差异。
