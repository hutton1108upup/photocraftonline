Windows：下载、解压并打开样例

  1. 打开 Windows 设置 → 系统 → 系统信息，确认是 x64、ARM64 还是 32 位；下面的实测使用 x64 Portable ZIP。
  2. 下载对应 ZIP，并按下方方法核对 SHA256。右键 ZIP → 全部解压，进入完整解压后的程序文件夹；不要直接从压缩包内运行。
  3. 运行 solidcraft.exe，确认界面右上方显示 v0.16.2。若使用 MSI，按安装程序提示安装，再从开始菜单打开；本站此次没有测试 MSI 安装。
  4. 下载 60 mm 可编辑样例。在 SolidCraft 中选择 File → Open，打开它，保留原件。

成功检查：看到一个带两个通孔的安装板，模型树中有 MountingPlate，右上角版本为 v0.16.2。此次通过本机应用控制接口打开样例，测得一个实体及 60 × 30 × 4 mm 包围盒；这不是 MSI、其他系统或整套建模重做的验证。

若系统提示无法运行，先核对来源、校验值、架构和完整解压情况，再按官方针对该版本的启动说明处理。不要仅因为出现系统提示就改用不明来源安装包。

macOS 与 Linux：按包类型启动

macOS DMG

  1. 下载 Universal DMG，打开后将 SolidCraft.app 拖到 Applications。
  2. 从 Applications 启动；首次系统提示以官方当前说明为准。
  3. 打开样例，确认模型可见，再另存自己的副本。

Linux AppImage

先执行 uname -m 确认架构。在下载目录中，x86_64 示例命令如下；其他架构要使用自己下载的准确文件名。DEB、RPM、Flatpak 按其各自说明安装，不执行 AppImage 命令。

chmod +x solidcraft-0.16.2-linux-x86_64.AppImage
./solidcraft-0.16.2-linux-x86_64.AppImage

成功标志是应用窗口能打开样例。以上 Mac / Linux 步骤依据官方资料，本站此次未在这些系统启动验证。

核对下载文件：SHA256 必须对应同一版本和文件名

在 Windows 的 ZIP 所在文件夹打开 PowerShell，复制执行：

Get-FileHash .\solidcraft-0.16.2-windows-x64-portable.zip -Algorithm SHA256

与同一发行页的 SHA256SUMS.txt 比对。本站实际下载的 x64 便携包结果为：

c1cdc511ec70a77536cb22bbcea5c9bcda6e0d29622fc5cb9c935d9a1c3977ef

文件名、版本或架构不同，就不能用这个校验值。文件核验不等于已验证全部功能。

从旧版本升级：先备份，再手动下载当前版本

  1. 复制备份自己的 .solidcraft 设计和旧版程序，保留原件。
  2. v0.14.0 及更早版本的内置更新可能无法跟随仓库迁移。按 官方迁移说明手动下载新版，不要只等待旧版更新提示。
  3. 先在新版打开设计副本；核对尺寸、实体和时间线，再另存一个新文件名。不要假设新版本保存的文件还能被旧版打开。

本站 v0.12.0 安装板教程和 MCP 案例保留原始步骤。v0.16.2 已验证能打开该 60 mm 样例，但没有重新验证所有旧脚本、修改参数及导出流程。查看当前兼容说明。

下载后打不开：先区分软件与文件问题

  • 程序不启动：核对 OS / CPU、校验值与完整解压；记录完整报错。
  • 窗口打开但样例看不到：先打开本站小样例，对照上图检查模型树和版本。
  • 只有自己的设计打不开：保留原文件，核对创建该文件的版本和官方兼容说明。
  • 需要反馈时，记录版本、系统、GPU 与错误；不要把私人设计放进公开 Issues。
