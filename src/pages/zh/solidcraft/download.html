Windows：运行便携版

  1. 在“设置 → 系统 → 关于”确认是 x64 电脑，再下载上表 Portable ZIP。
  2. 右键 ZIP → 全部解压，把整个文件夹解压到“下载”或自己的工作目录；不要直接从压缩包中启动。
  3. 打开解压后的目录，双击 solidcraft.exe。命令行程序 solidcraft-cli.exe 也在同一目录，教程会用到它。
  4. 确认标题栏显示 v0.12.0，并能打开教程提供的 mounting-plate-60.solidcraft，才算启动和文件读取成功。

官方说明该版本安装包尚未签名。如遇 SmartScreen，先核对来源及校验和；确认后按官方说明选择“更多信息 → 仍要运行”。使用 MSI 时按安装向导完成，再从开始菜单打开。

macOS 与 Linux 安装步骤

macOS

  1. 打开 DMG，将 SolidCraft.app 拖入 Applications。
  2. 从 Applications 启动；首次打开的系统提示按官方安装说明处理。
  3. 打开一个示例设计，确认可显示实体后再保存自己的副本。

Linux AppImage

  1. 用 uname -m 确认架构，下载对应 AppImage。
  2. 将文件放入自己的应用目录，在文件属性中允许作为程序执行；或运行下方命令。
  3. 启动后打开示例文件。Flatpak、Snap 与发行版软件包按官方对应说明安装。
chmod +x solidcraft-0.12.0-linux-x86_64.AppImage
./solidcraft-0.12.0-linux-x86_64.AppImage

下载校验与升级

在 Windows PowerShell 中进入 ZIP 所在文件夹，复制执行以下命令；将结果与同一发行页的 SHA256SUMS.txt 中同名文件对应的哈希比较。便携包的预期值如下。

Get-FileHash .\solidcraft-0.12.0-windows-x64-portable.zip -Algorithm SHA256
# 2c66701d4c66630f3d1988e43ceaf5c4b2179baf89dddb15ea70b3e03a0e24c1

升级前复制一份设计文件。v0.12.0 保存的新格式不能由 v0.11.x 或更早版本打开；不要用唯一的原件试升级。SolveCraft 旧名称迁移、Flatpak 应用 ID 变化见官方兼容文档。

打不开时先检查什么？

  1. 确认系统和处理器与发行文件一致，且便携包已完整解压。
  2. 浏览器版黑屏或图形异常时，试用官方文档列出的 ?webgl 地址；先导出已有设计副本。
  3. 命令行提示找不到 solidcraft-cli 时，在其所在目录使用 .\solidcraft-cli.exe，或在客户端配置里填写完整路径。
  4. 仍失败时记录版本、系统、显卡及完整错误，到官方 Issues 查询。
