从你看到的现象开始排查。以下步骤帮助定位原因，不保证所有浏览器或文件都能运行。

1. 检查浏览器与图形支持

  1. 使用已更新的桌面 Chrome 或 Edge，再次打开编辑器。手机浏览器的操作方式和 GPU 支持可能不同。
  2. Chrome：打开 Settings → System，检查 “Use graphics acceleration when available”。Edge：在设置中搜索 “graphics acceleration”。修改后重启浏览器。
  3. 如果本站提示 WebGPU 不可用，请换一个支持的桌面浏览器，或尝试桌面版。不把关闭浏览器安全保护或启用实验参数作为通用解决办法。

2. 编辑器停在加载状态时

  1. 首次加载需要下载当前约 25 MB 的 WebAssembly 文件，速度受网络影响。
  2. 如果还没打开文档且出现重试提示，点击 Retry editor。重新加载会丢失编辑器中未保存的工作。
  3. 打开开发者工具 → Network，刷新后查看 .wasm 或 photocraft-web-…js 请求是否失败。HTTP 错误或被阻断的请求是加载问题，不能据此判断图片损坏。
  4. 若文件请求成功但仍无法启动，可尝试新标签页和另一款支持的浏览器。反馈前记下可见错误。

3. 文件打不开时

先打开教程里的小 PNG。若能打开，再测试自己文件的副本。复杂 PSD 或大图的失败原因可能与编辑器启动问题不同。

4. 尝试桌面版本

如果问题来自浏览器图形支持，可以尝试运行环境不同的桌面原生版。从官方发布页选择正确系统和架构；桌面版是可尝试的替代方案，不保证文件问题必然消失。
