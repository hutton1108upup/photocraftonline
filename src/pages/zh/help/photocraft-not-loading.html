PhotoCraft not opening：先确认是哪一种问题

  • 只看到加载提示、空白或 WebGPU 提示：从下方浏览器与网络检查开始。
  • 编辑器已出现，但某个 PSD 或图片打不开：直接看文件检查。
  • 下载到电脑的 EXE 或应用无法启动：直接看桌面启动检查。

1. 在线编辑器不启动：检查浏览器图形支持

  1. 使用更新后的桌面 Chrome 或 Edge，打开本站编辑器。编辑区域出现工具栏和画布，才表示启动完成。
  2. 若显示“此浏览器未提供 WebGPU”，在 Chrome 设置 → 系统查看“使用图形加速功能（如果可用）”；Edge 可在设置搜索“图形加速”。更改后重启浏览器再试。
  3. 仍显示相同提示时，换支持图形加速的桌面浏览器，或查看官方桌面下载。不要通过关闭浏览器安全保护来绕过问题。

成功检查：加载提示消失、编辑器工具栏与画布出现。出现浏览器页面或页头本身不等于编辑器已启动。

2. 一直加载或下载失败：检查编辑器资源

  1. 首次会请求约 25 MB 的 WebAssembly 文件，先确认网络有进展，不要连续刷新。
  2. 未打开工作文档时，可以点击“重试编辑器”。若已有未保存内容，先处理备份；重试和刷新会丢失未保存修改。
  3. 仍不能启动时，按 F12 打开开发者工具 → Network，刷新后查看 .wasm 或 photocraft-web-…js 请求是否失败；记录状态码或阻止原因。
  4. 资源成功返回但仍失败时，记录页面上的完整错误，再换浏览器核对。不要因此判断原图片损坏。

成功检查：资源加载完成，随后编辑器界面出现；单独一个 HTTP 200 不能证明引擎初始化成功。

3. 编辑器已启动，但某个图片或 PSD 打不开

  1. 下载本站640 × 400 练习 PNG，在编辑器中先尝试打开它。
  2. 练习图成功后，再打开自己文件的副本。若只有复杂 PSD 或大图失败，记录格式、大小和出现错误的步骤；不要覆盖原件。
  3. 按教程保存与导出，检查浏览器下载列表，再重新打开导出的 PNG。

成功检查：练习图显示出来，导出的 PNG 在重新打开后仍显示图像。这个小样例不能证明所有 PSD 图层、字体或效果都兼容。

4. 桌面程序打不开：确认包类型、架构与文件

  1. 先从下载页选择自己的系统和 CPU。源码 ZIP、Web ZIP 和桌面安装包用途不同。
  2. Windows 便携版需右键 ZIP → 全部解压，然后在完整文件夹内运行程序；MSI 则走安装流程。校验值必须来自同一发行版、同一文件名。
  3. 如果程序能打开但只有某份文档失败，回到上方文件检查；不要反复重新安装来处理单个文件问题。
  4. 保留系统提示和完整报错，按官方当前版本说明处理。本站此次未重新测试桌面安装或 Mac/Linux 启动。

成功检查：桌面编辑器窗口出现，并能打开练习 PNG。下载完成、解压成功都不等于程序已经能工作。

5. 仍未解决：整理可复现信息

记录操作系统、浏览器版本、本站构建 ID、卡住的具体步骤、可见错误和去除私人内容后的截图。先搜索 官方 Issues；引擎问题和本站页面加载问题需要分别描述。不要公开上传私人图片或设计文件。
