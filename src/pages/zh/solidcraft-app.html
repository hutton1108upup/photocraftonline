SolidCraft 是什么？

SolidCraft 是用 Rust 开发的开源参数化 3D CAD。先在平面上绘制草图，再添加尺寸和约束，把轮廓拉伸成实体；之后修改参数，时间线会重新计算模型。它适合先从安装板、支架和简单外壳等零件开始体验。

有 Windows、macOS、Linux 桌面发行包，也有浏览器应用和命令行工具。官方将其定位为仍在早期发展的项目；能完成一个简单案例，不代表所有工业设计流程都已覆盖。

SolidCraft、SolveCraft 与 CADCraft 的区别

SolveCraft 是 SolidCraft 的旧名称，旧教程可能仍出现 solvecraft-cli 和 .solvecraft。新教程优先使用 solidcraft-cli 与 .solidcraft；升级前先备份旧设计，按官方兼容说明处理。

本站的 CADCraft 指南 面向另一个采用 AutoCAD 式命令工作流的制图工具；SolidCraft 本页聚焦参数化三维零件。Craft 工具导航提供相关工具入口。不同仓库和相似名称不能作为官方隶属关系的证明。

常见问题

本站是 SolidCraft 官方网站吗？

不是。官方发行版、问题反馈和文档请使用上游 GitHub 仓库。本站提供独立指南与原创练习案例。

有中文版软件吗？

中文教程与软件界面语言是两回事。本教程使用英文界面标识并附中文解释；界面可用语言以所下载版本的设置为准。

SolidCraft 是 Fusion 360 官方版吗？

不是。它是独立开源项目，不由 Autodesk 认可或运营。选择工具前按自己的文件、功能和交付要求核对。
