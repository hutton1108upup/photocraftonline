Windows：独立安装还是 ArtCraft Launcher？

只使用 PhotoCraft 时，可继续选择本页 MSI 或便携 ZIP。需要管理多个 Craft 应用时，可查看官方 Launcher，它按系统和处理器选择各应用的发布文件并提供更新入口。Launcher 不是 PhotoCraft MSI，也不是本站编辑器。

  1. 打开官方 Launcher 发布页，阅读该版本说明，选择匹配 Windows 系统和架构的文件。
  2. 按该发布的校验与安装说明完成操作；不要把 PhotoCraft 的文件校验值用于 Launcher。
  3. 在 Launcher 中选择 PhotoCraft，核对所显示版本，再按其具体提示安装或更新。
  4. 启动 PhotoCraft，用项目副本检查打开、保存与导出。

使用 MSI 安装 PhotoCraft

  1. 下载与你的系统类型匹配的 MSI，并按校验步骤核对文件。
  2. 在资源管理器中双击 MSI。上游安装向导提供安装目录、确认安装、进度与完成页面，默认目录为 Program Files 下的 PhotoCraft。
  3. 阅读安装目录和提示；如果你决定安装该包，按向导完成所需系统确认。
  4. 安装完成后，从开始菜单打开 PhotoCraft。选择 File → Open，用一张练习图片确认画布能显示，再检查导出结果。

看到完整应用窗口和样例图片才算启动成功；仅出现安装完成提示还不够。上述向导行为依据发布标签中的上游打包配置，本站未执行 MSI 安装验收。

使用 Portable ZIP，不安装到系统

  1. 选择文件名含 windows、正确架构与 portable.zip 的文件。GitHub 的 Source code ZIP 和 Web ZIP 不是这个便携应用。
  2. 在下载文件夹右键 ZIP → 全部解压（Extract All）。解压完整文件夹到有写入权限的位置，不在 ZIP 内直接运行程序。
  3. 打开解压后的子文件夹，运行 photocraft.exe。保持 portable.txt 和其他文件与它放在一起。
  4. 用 File → Open 打开练习图，导出到独立文件并重新打开确认结果。

上游的 portable.txt 说明：便携设置、笔刷预设和恢复文件存入程序旁的 PhotoCraftData。如果程序目录只读，上游说明便携模式可能退回 %APPDATA%\Photocraft。移动或更新时先确认数据位置，保留完整文件夹与已有数据；恢复文件不能代替作品备份。

更新、卸载与作品保留

更新前，把原稿、可编辑文档和导出结果保存到独立作品文件夹并备份。查看最新发行版，重新匹配系统、架构并核对校验值。本页固定已检查的 v0.10.0，不会自动改变你的安装。

MSI 版可按 Windows 11 的设置 → 应用 → 已安装的应用，找到 PhotoCraft 后选择卸载；Windows 10 的相关入口为“应用和功能”。如果入口不适用，参考微软的卸载说明。不要假设卸载会自动备份作品或保留全部设置。

便携版关闭后可移动整个文件夹；删除前先单独备份作品和需要的 PhotoCraftData。使用新版本时先解压到另一个文件夹验证，不直接覆盖唯一副本。
