PhotoCraft Mac 版

Apple Silicon 与 Intel 通用 DMG。

photocraft-0.6.0-macos-universal.dmg

  1. 从官方发布页下载 universal DMG。
  2. 打开 DMG，把 PhotoCraft 拖入 Applications。
  3. 打开应用。若被 macOS 阻止，先核对发布者与官方来源，再按系统具体提示处理；不要关闭系统安全保护。

PhotoCraft Windows 版

提供 x64、arm64 与 x86。先打开 Settings → System → About，查看 System type，再选择对应文件。

photocraft-0.6.0-windows-x64.msi

photocraft-0.6.0-windows-x64-portable.zip

ARM64 或 32 位 x86 设备请在发布页 Assets 中选择对应 MSI 或 portable ZIP。

  1. 下载对应 MSI 并运行安装程序。
  2. 按安装窗口提示完成，再打开 PhotoCraft。
  3. 使用 portable ZIP 时，先把整个压缩包解压到一个文件夹，再运行其中的应用。

PhotoCraft Linux 版

x86_64 与 aarch64 均提供 AppImage、DEB、RPM、Flatpak 和 tar.gz。按架构和发行版选择。

photocraft-0.6.0-linux-x86_64.AppImage

兼容的 Debian/Ubuntu 系统可选择 DEB，兼容的 RPM 系统可选择 RPM。安装前查看上游系统要求与依赖。

AppImage 可能需要执行权限及发行版运行时支持。本页不把未实测的 Linux 安装命令写成已验证步骤。
