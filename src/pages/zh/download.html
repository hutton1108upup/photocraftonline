安装 MSI 版本

  1. 保存与系统对应的 MSI，在“下载”文件夹中双击打开。
  2. 按安装向导选择安装目录并点击 Install；确认要安装此包时，允许 Windows 的安装提示。
  3. 在 Finish 页面启动 PhotoCraft，或打开开始菜单搜索 PhotoCraft。

成功检查：看到 PhotoCraft 窗口；点击 File → Open，选择一张测试图片，确认图片出现在画布中。

运行 portable ZIP，免安装

  1. 选择名称同时含 windows 和 portable 的对应 ZIP。“Source code (zip)”是源码，不是 Windows 应用。
  2. 在“下载”文件夹右键 ZIP → 全部解压缩，选择可写文件夹，完整解压。
  3. 打开解压后的文件夹，双击 photocraft.exe。保留同目录的 portable.txt 和其他文件，不要直接在压缩包内运行。

成功检查：看到 PhotoCraft 窗口；点击 File → Open，选择一张测试图片，确认图片出现在画布中。

PhotoCraft Mac 版

Apple Silicon 与 Intel 共用一个 Universal DMG。选择桌面版 DMG，不要误选单独的命令行工具 ZIP。

下载 Universal DMG

photocraft-0.6.0-macos-universal.dmg

  1. 保存以 -macos-universal.dmg 结尾的文件，在 Finder → 下载中双击打开。
  2. 把 PhotoCraft 拖入 Applications（应用程序），等待复制完成，再推出磁盘映像。
  3. 在 Finder → 应用程序中双击 PhotoCraft；若 macOS 询问是否打开下载的应用，核对后点击“打开”。

成功检查：看到 PhotoCraft 窗口；点击 File → Open，选择一张测试图片，确认图片出现在画布中。

若提示开发者未验证，先核对发布来源与发布者；仅针对该提示，系统设置 → 隐私与安全性中可能显示“仍要打开”。若提示应用已损坏或含恶意软件，应停止并查看上游帮助，不绕过该警告。

PhotoCraft Linux 版

打开终端执行 uname -m。x86_64 对应 64 位 Intel/AMD，aarch64 对应 ARM64。独立运行选 AppImage，Debian/Ubuntu 选 DEB，Fedora/RHEL/openSUSE 选 RPM，使用 Flatpak 的系统可选 Flatpak 包。

uname -m

以下命令对应已核验的 v0.6.0 文件。在文件管理器中打开下载文件所在文件夹，选择“在终端中打开”。只执行所选格式的命令；任一步报错就停在该步，先查看错误。

PhotoCraft 下载常见问题

下载 PhotoCraft 需要付费吗？

这些安装包来自免费、开源的上游项目，无需在本站购买或注册账号。

所有 ZIP 都是免安装应用吗？

不是。Windows 免安装包的文件名包含 portable；Source code 是给开发者的源码，web ZIP 是用于自行部署网站的构建包。

不知道架构时应该怎么选？

Windows 查看“系统类型”，Linux 执行 uname -m；Mac 的 Intel 与 Apple Silicon 共用 Universal DMG。不要把本站系统推荐当成处理器架构识别。

桌面版能解决所有浏览器问题吗？

它可以避开浏览器特有的限制，但应用与文件兼容仍需测试。 加载与浏览器故障帮助

photocraft-web ZIP 用于部署浏览器版本，不是桌面安装包。在发布页 Assets 中获取，并按上游托管文档部署。
