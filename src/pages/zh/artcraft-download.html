下载前确认文件类型

  • MSI：Windows 安装包；Portable ZIP：解压后运行，保留配套文件。
  • DMG：macOS 桌面应用；Linux 包按架构及发行版选择。
  • Web ZIP：用于自托管，不能作为桌面安装包直接运行。
  • Source code ZIP：源码，通常需要构建；普通下载用户选择编译好的发行文件。
