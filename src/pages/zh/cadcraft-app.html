CADCraft 是什么？

CADCraft 是 ArtCraft 系列中用 Rust 实现的开源制图应用，采用类似 AutoCAD 的命令行工作流。它用于技术图纸，PhotoCraft 则用于像素图片编辑。搜索 cadcraft app 或 cadcraft github 时，以 storytold/cadcraft 仓库核对身份，同名培训服务或其他软件不能据此认定为同一产品。

上游仍标注为早期开发。先用简单图纸副本核对输出，再决定是否迁移已有 CAD 工作流。 查看 CADCraft 与 AutoCAD 对比。

安装或运行 CADCraft

  1. 从官方发行版下载，使用 Get-FileHash 文件路径 -Algorithm SHA256，与同一发行版的 SHA256SUMS.txt 对照。文件路径替换成实际下载位置。
  2. Windows 便携版：右键 ZIP → 全部解压，进入解压后的文件夹运行 cadcraft.exe。MSI 是另一种安装方式；本次实测使用便携版。
  3. Mac：打开 Universal DMG，将应用复制到 Applications。Linux AppImage：在文件所在目录执行 chmod +x cadcraft-0.6.2-linux-x86_64.AppImage，再执行 ./cadcraft-0.6.2-linux-x86_64.AppImage。这些步骤按上游文件整理；本次未实测 Mac 和 Linux 启动。
  4. 成功标志：制图窗口打开，通过“文件 → 打开”能看到练习 DXF。保留原文件。

界面语言在“编辑 → 界面语言”选择。v0.6.2 README 列出了简体中文，本次 Windows 截图也显示中文；文字显示取决于可用的中文字体。

本次 Windows x64 便携包与 Web ZIP 均匹配官方 SHA256SUMS。这是文件完整性核验，不能保证所有图纸或设备的使用结果。

DXF、DWG 与兼容性边界

对应版本 README 介绍了 DXF／DWG 读写、SVG／PNG 导出及 PDF 出图。本次 Windows 检查中，DXF 保存重开和 CADCraft 自身 DWG 转换重开均保留矩形、两个圆和一个标注；未在 AutoCAD 中测试。浏览器检查只覆盖 DXF。

未支持的实体可能在保存时丢失。SHX 字体、高级 3D、自定义对象、外部参照和复杂打印需要单独核验。不要覆盖生产图纸来测试兼容性。 格式支持说明。

CADCraft 常见问题

使用 CADCraft 需要安装 Rust 吗？

运行已编译的桌面文件或浏览器应用不需要。自行编译源码才需要 Rust。

本站是官方 CADCraft 在线应用吗？

不是。本站独立托管未经修改的官方 v0.6.2 Web 构建。官方 Web ZIP 是自行托管文件，不是官方公开在线试用地址。
