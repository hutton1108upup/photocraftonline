这里的“AI Photoshop Clone”是什么意思？

AI 辅助开发、智能体控制编辑与生成式图片工具是不同概念。PhotoCraft 是开源的 Photoshop 风格编辑器；本站固定浏览器构建未接入 AI 助手或生成式模型服务。

上游文档介绍了命令自动化和 MCP，但 v0.8.2 README 将 AI/生成式功能列为缺口。本页的 AI 关键词不会为托管引擎增加这些能力。

开始编辑前的常见问题

在线编辑器可以免费使用吗？

可以。本站托管编辑器与图文练习流程无需付款、本站账号或桌面安装。

AI Photoshop Clone 包含生成式填充吗？

不包含。本站构建没有接入 AI 助手、文生图模型或 Generative Fill 服务。这里提供的是 Photoshop 风格的 PhotoCraft 编辑器入口，不承诺 AI 生成能力。

可以保存 PSD 并继续编辑吗？

本站固定 Web 构建已验证保存并重新打开简单的双像素图层 PSD，再导出保留修改的 PNG。复杂 PSD、字体、智能对象与 Photoshop 往返仍需单独检查。

应该使用哪个浏览器？

这些样例在 Windows 桌面 Chrome 中实测。请使用支持图形加速的已更新桌面浏览器；本站没有验证所有浏览器、手机或操作系统。

图片文件如何处理？

托管引擎在浏览器中运行，文档记录的本地样例流程未观察到图片上传。网站托管与统计请求另有范围，具体说明见隐私和安全页面。

可以离线使用吗？

在线编辑器启动前需要下载资源。本站未验证持久离线启动或 Service Worker 缓存；需要离线使用时，请查看官方桌面版并验证自己的流程。

为什么找不到导出的图片？

点击 File → Export → Quick Export as PNG，再查看浏览器下载列表及保存或权限提示。文件保存完成前保留标签页；下方提供加载和导出帮助。

这是 Adobe Photoshop 或 ArtCraft 官方网站吗？

不是。PhotoCraft 是独立开源编辑器，本站也独立于 Adobe 与 ArtCraft。
