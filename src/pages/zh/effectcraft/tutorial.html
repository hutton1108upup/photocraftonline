EffectCraft CLI 入门：保存与动画导出

用原创两秒动画练习 EffectCraft：读取关键帧、修改位置、保存并重新打开原生项目，再按已验证的 Windows CLI 步骤导出 GIF 和 PNG。

准备关键帧修改重开导出范围

练习目标：保存、重开并渲染一个原生动画

这个两秒练习由背景和 Moving Block 两个纯色图层组成，24 fps、640 × 360。样例从 x=80 移动到 x=560；你将把末端改为 x=500，保存新项目、重新读取并导出 GIF/PNG。

以下 CLI 路径已用官方 Windows x64 v0.9.2 包验证。如果想用鼠标操作，请打开下面单独的桌面图文教程；两个教程使用同一个原始项目。

查看原始两秒 GIF 预览

1. 下载包和项目，打开正确的终端目录

  1. 从产品指南下载并核验 Windows x64 便携 ZIP；确认目标电脑确实是 x64。ARM64/x86 文件另列在产品页，本教程未验证这些架构。
  2. 完整解压 ZIP。打开包含 effectcraft-cli.exe 的子文件夹，不在 ZIP 内运行。
  3. 下载下方 first-motion.ecproj，将文件复制到同一个子文件夹。文件扩展名保留 .ecproj。
  4. 在资源管理器地址栏输入 powershell 并按 Enter。终端当前目录应同时包含 CLI 和练习项目。只在这个目录逐条执行下面命令；失败就停在对应步骤检查报错。

下载原生练习项目 选择官方程序包 · 下载原始预览 GIF

2. 读取合成与关键帧

.\effectcraft-cli.exe info --project first-motion.ecproj --json

成功输出应显示 First Motion、640 × 360、duration 2、frameRate 24 和两层。然后查看末端位置：

.\effectcraft-cli.exe get "First Motion" "Moving Block" transform/position --time 1.5 --project first-motion.ecproj --json

应看到两个关键帧：第 0 秒 [80,180,0]，第 1.5 秒 [560,180,0]。第三个 0 是位置的 Z 分量。关键帧让同一属性在不同时间拥有不同值，中间由插值生成运动。

3. 改变末端位置，保存另一个项目

.\effectcraft-cli.exe set "First Motion" "Moving Block" transform/position "[500,180]" --time 1.5 --project first-motion.ecproj --save-as first-motion-edited.ecproj --json

成功结果包含 saved，目标为 first-motion-edited.ecproj。原始文件仍保留；末端关键帧现在应为 [500,180,0]。只改一个参数，先验证简单结果。

4. 重新读取保存的项目，确认修改已保留

.\effectcraft-cli.exe get "First Motion" "Moving Block" transform/position --time 1.5 --project first-motion-edited.ecproj --json

这是一个新的 CLI 调用，重新读取磁盘上的新项目。应显示两个关键帧，末端值 [500,180,0]；仅看到修改命令成功还不足以确认保存与重开。

5. 导出 GIF 和末帧 PNG

.\effectcraft-cli.exe render --project first-motion-edited.ecproj --comp "First Motion" --out first-motion-edited.gif --format gif --start 0 --end 2 --fps 24 --json
.\effectcraft-cli.exe render-frame --project first-motion-edited.ecproj --comp "First Motion" --time 1.5 --out first-motion-edited.png --json

文件写入当前目录。GIF 应为 640 × 360、48 帧；PNG 应显示方块中心 x=500、y=180。打开两个文件检查运动与末端位置，再决定是否用于后续任务。本站下载的原始 GIF 末端为 x=560，和你修改的结果不同。

失败时检查什么？

  • 提示找不到命令：确认终端当前目录含 effectcraft-cli.exe，且完整解压了程序包。
  • 提示找不到文件：确认 first-motion.ecproj 在同一目录，未被加上 .txt 后缀。
  • 没有 First Motion 或 Moving Block：先运行 info，使用本教程原始项目核对名称；不要把示例命令套到其他项目。
  • 保存或导出失败：检查文件夹可写、完整报错和输出路径；保留原始项目。
  • Web 图形设备丢失：旧版 v0.8.0 曾在本机出现；本轮未复测 v0.9.2 Web。记录具体版本与报错，不把旧版现象当作新版结论。

可以把 AE 项目改扩展名后打开吗？

不可以。这里使用真正的 EffectCraft 原生项目；改扩展名不会转换文件结构。

样例需要字体或外部素材吗？

不需要，只有两个纯色图层。

可以直接投入客户项目吗？

这个简单练习只验证小范围流程，不能替代对完整项目、效果和输出要求的验证。
