WordCraft 是什么？如何确认身份？

WordCraft 是 ArtCraft 用 Rust 实现的开源文字处理软件。上游介绍了 Word 风格功能区、样式、表格、审阅与引用工具，以及 DOCX 读写和 PDF 导出。它是独立项目，不是 Microsoft Word，也不是微软运营的服务。

WordCraft 也被用于写作工具、研究项目和文字游戏。搜索 wordcraft download 或 wordcraft github 时，以 storytold/wordcraft 与 getartcraft.com/apps/wordcraft 确认本页所指编辑器；同名不能证明开发者或功能相同。

安装或运行 WordCraft

  1. 下载匹配文件，并读取同一发行版的 SHA256SUMS.txt。在下载目录打开 PowerShell，用下方命令与实际文件名核对；结果必须匹配该文件的校验值。
  2. Windows 便携版：右键 ZIP → 全部解压，进入解压后的子文件夹，运行 wordcraft.exe，保留配套文件。也可运行匹配的 MSI 并按提示安装。
  3. macOS：打开 Universal DMG，将 WordCraft 复制到 Applications，再从该目录打开；核对系统提示中的发布者信息。
  4. Linux AppImage：在文件目录打开终端，按下方命令赋予执行权限并运行。其他格式按该发行版的发行版安装说明操作。
Get-FileHash ".\wordcraft-0.8.0-windows-x64-portable.zip" -Algorithm SHA256
chmod +x wordcraft-0.8.0-linux-x86_64.AppImage
./wordcraft-0.8.0-linux-x86_64.AppImage

WordCraft 基础使用：先完成一个小型 DOCX

  1. 新建文档，或通过“文件 → 打开”选择简单 DOCX 副本。先练习标题、短段落与小表格，再测试复杂交付文档。
  2. 使用“开始”功能区的样式设置标题和正文，检查实际中文字体与行距；中文菜单不代表与 Word 分页完全一致。
  3. 另存为新文件名的 DOCX，关闭后重开副本，检查文字、样式、表格单元格与图片，保留原文件。
  4. 在“文件”页导出 PDF。打开 PDF 核对页数、中文字符、可选中文字和裁切情况，并保留 DOCX 作为可编辑原稿。
  5. 接收方使用 Microsoft Word 时，还需在那里打开保存后的 DOCX。导出 PDF 成功本身不能验证 Word 兼容性。

以上为桌面界面的新手操作清单，未做 GUI 实测。上方已提供范围较小的 CLI 小样结果与练习文件。

WordCraft 常见问题

WordCraft 免费吗？

上游项目采用 MIT／Apache-2.0 开源许可，本指南链接到公开发行文件；不能据此认定所有 ArtCraft AI 或第三方托管服务都免费。

可以在本站在线使用 WordCraft 吗？

目前不可以。本站现有托管编辑器为 PhotoCraft 与 CADCraft，本页提供 WordCraft 指南。上游 Web ZIP 可以另外托管，它不是可直接打开的官方试用链接。

DOCX 排版会与 Microsoft Word 完全一致吗？

不能假定分页、字体或对象保留完全一致。用副本在两种应用中核对，并检查实际交付 PDF。

有中文界面就代表完整支持中文文件吗？

菜单翻译、输入、字体排印、布局与导出是不同检查项，应使用实际样例验证。
