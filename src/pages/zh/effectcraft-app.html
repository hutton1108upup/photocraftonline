EffectCraft 是什么，适合什么任务？

EffectCraft 是 ArtCraft 系列中的免费开源动态图形与合成工具，用 Rust 编写，目标是提供熟悉的 After Effects 式工作流程。适合先尝试字幕、形状动画和图层合成；官方还介绍表达式、效果、3D 摄像机和灯光，但本站没有验证这些能力的完整表现。

v0.9.2 官方说明仍将它标为 alpha，并指出尚不能替代客户项目中的 After Effects。本站是独立指南网站，只托管 PhotoCraft；这里不提供 EffectCraft 在线编辑器，也不是 Adobe 或 ArtCraft 的官方网站。

独立安装还是 Launcher？

只需要 EffectCraft 时可选择上述独立包；管理多个 Craft 应用时，可查看官方 Launcher。Launcher 与 EffectCraft 独立发布，版本和校验值不同。Web ZIP 用于自行托管网站，Source code ZIP 用于编译，都不是桌面安装程序。 Launcher 官方发布

安装概览与启动检查

  1. Windows MSI：核对文件与 SHA256，双击匹配的安装包并按其提示安装。便携 ZIP：右键“全部解压”，进入完整解压后的文件夹运行 effectcraft.exe，不在压缩包内启动。
  2. Mac：在访达打开官方 DMG，按包内提示将应用放入“应用程序”，再从该目录启动。
  3. Linux AppImage：在下载目录终端执行 chmod +x 文件名，再运行该文件；把文件名替换成实际下载的完整名称。
  4. 启动成功后打开本站原生样例，确认合成、两层和两个关键帧。保存到另一个文件，再检查渲染输出；安装完成提示本身不代表工作流程通过。

2026 年 10 月 13 日已验证 Windows 11 x64 便携版的桌面打开、关键帧修改、另存、重开及渲染队列 GIF 导出，同时复测包内 CPU CLI。MSI、Mac/Linux 安装与 Launcher 尚未验收。若遇到图形设备或启动错误，记录系统、显卡、版本和完整报错，查看上游 Issues。核验文件时使用同一发布的校验清单；校验一致不等于所有环境都能运行。

EffectCraft 下载与使用常见问题

它能直接打开我的 AE 模板吗？

不能按此假设。v0.9.2 官方说明不支持 .aep/.aepx、.mogrt/.ffx 和 AE 插件。本站练习是原生 .ecproj。

普通用户需要 Rust 吗？

运行官方桌面包或包内 CLI 不需要安装 Rust；源码编译是另一个任务。

本站可以直接运行 EffectCraft 吗？

本站提供指南和样例，托管编辑器仍为 PhotoCraft。上游 Web ZIP 用于自行托管。

教程里的快捷键可以直接用吗？

Windows v0.9.2 实际按键验证了 Ctrl+O 打开与 P 展开位置。另存、加入渲染队列通过菜单验证，菜单显示对应快捷键 Ctrl+Shift+S 与 Ctrl+M。教程同时给出鼠标路径；其他系统的键位未测试。
