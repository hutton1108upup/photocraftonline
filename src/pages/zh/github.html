PhotoCraft 是开源软件吗？

上游 PhotoCraft 仓库公开 Rust 源码，并列出 MIT 和 Apache-2.0 许可证。复用或分发前请阅读实际的 MIT 许可证、Apache-2.0 许可证及项目相关声明。

开源描述源码与许可，不是对兼容性、安全、全部二进制行为或托管网站政策的认证。本站静态网页外层与上游编辑器是不同项目。来源与安全核验。

FreePhotoCraft.online 与上游是什么关系？

ArtCraft 的项目介绍位于 getartcraft.com/apps/photocraft。上游仓库维护编辑器源码、发行版和引擎问题追踪。

FreePhotoCraft.online 独立托管未修改的 WebAssembly 引擎文件，并提供导航、加载反馈和中英文指南。本站不拥有 PhotoCraft，也不由上游运营、认可或赞助。Web 引擎只有在本站主动更新时才会改变，不自动等于最新桌面版。

怎样从 GitHub Releases 下载？

  1. 打开发行版列表，选择需要的版本，阅读发布说明和系统要求。
  2. 展开 Assets，选择符合系统与架构的安装包；不要把源码 ZIP 当成安装包。
  3. 如果该版本提供 SHA256SUMS.txt，从同一发布下载，并核对完全相同文件名的校验值。

已核对的文件名与平台步骤见桌面下载指南。发布内容会变化，本页不会预设未来版本的安装包名称。

PhotoCraft Rust：使用程序与编译源码是两回事

普通用户运行桌面安装包或本站 Web 编辑器，不需要安装 Rust。开发者查看或编译源码时，才需要 Rust 工具链和目标系统依赖。本站使用已编译 WebAssembly，不是在浏览器中运行 Cargo。

准备编译前先核对

  1. 选择要构建的提交或发布标签，阅读同一版本的 README、Cargo.toml 与工具链配置；不要把 main 的要求套到旧标签。
  2. 核对 Rust/Cargo 版本、Windows 链接器及系统依赖。官方产品页当前写明 Rust 1.90 或更新版本，实际仍以目标版本配置为准。
  3. 按官方流程克隆源码、进入仓库并运行构建；构建失败时保留完整错误，不跳过缺失依赖。
  4. 启动实际生成的程序，检查样例图片、保存和导出；编译完成不等于所有功能已验证。

本站未验证源码编译。请按下方目标版本的上游说明操作；已发布二进制的测试不代表源码构建通过。

自行托管 PhotoCraft Web 构建

  1. 打开发行版 v0.8.2，在 Assets 中找到 photocraft-web-0.8.2.zip，注意它与源码 ZIP 不同。
  2. 按该发行版 SHA256SUMS 核对文件，解压并阅读包内托管说明。
  3. 通过 HTTPS 提供解压后的静态文件，WASM 使用 application/wasm，JS 使用 JavaScript 类型，并保留许可证与署名文件。
  4. 在实际部署路径检查导入、编辑、下载和重开，再发布。本站现有引擎未升级为这个包。

GitHub 与开源常见问题

这里链接的是官方仓库吗？

本页外部源码入口指向上游仓库 storytold/photocraft；FreePhotoCraft.online 是独立网站。

下载源码 ZIP 就能安装吗？

不能。源码压缩包包含代码文件；安装应用应选 Assets 中的平台文件，需要自行编译时请按上游构建说明操作。

编辑器故障应向哪里反馈？

先搜索上游 Issues，再提供构建、浏览器或系统与不含敏感信息的复现步骤；不要公开私人文件。
