GridCraft 是什么？如何确认身份？

GridCraft 是 ArtCraft 用 Rust 实现的开源电子表格，采用 Excel 风格功能区、公式栏和工作表标签。上游介绍 XLSX 工作簿、CSV／TSV 数据交换、计算函数、表格、图表与透视表；它是独立项目，不是 Microsoft Excel。

GridCraft 也被其他游戏托管、像素绘图等产品使用。搜索 gridcraft download 或 gridcraft github 时，下载或跟随教程前，先核对 storytold/gridcraft 与 getartcraft.com/apps/gridcraft。

安装或运行 GridCraft

  1. 下载匹配文件，并读取同一发行版的 SHA256SUMS.txt。在下载目录打开 PowerShell，用下方命令与实际文件名核对；结果必须匹配该文件的校验值。
  2. Windows 便携版：右键 ZIP → 全部解压，进入解压后的子文件夹，运行 gridcraft.exe，保留配套文件。也可运行匹配的 MSI 并按提示安装。
  3. macOS：打开 Universal DMG，将 GridCraft 复制到 Applications，再从该目录打开；核对系统提示中的发布者信息。
  4. Linux AppImage：在文件目录打开终端，按下方命令赋予执行权限并运行。其他格式按该发行版的发行版安装说明操作。
Get-FileHash ".\gridcraft-0.6.1-windows-x64-portable.zip" -Algorithm SHA256
chmod +x gridcraft-0.6.1-linux-x86_64.AppImage
./gridcraft-0.6.1-linux-x86_64.AppImage

成功标志：GridCraft 窗口打开，并能打开小型 XLSX 文件。本页整理的是文档中的安装路径，不能保证所有设备启动；某步失败时先停止，按具体错误查看上游排查说明。

GridCraft 基础使用：小型工作簿与公式核对

  1. 新建空白工作簿，或打开小型 XLSX 副本。录入下方两行示例，先明确预期结果。
  2. B 列填数量，C 列填单价，D 列填乘法公式。在 D2 输入 =B2*C2，D3 输入 =B3*C3，D4 输入 =SUM(D2:D3)。
  3. 预期结果分别为 70、60、合计 130。将 B2 从 2 改为 4 后，D2 应为 140，合计应为 200，用于核对依赖公式是否重算。
  4. 另存为新文件名的 XLSX，关闭后重开。既检查显示值，也检查单元格公式；缓存值本身不能证明重算正常。
  5. 与 Excel 用户交换前，应在接收方需要的 Excel 版本中打开保存副本，检查公式、格式和图表。

GridCraft XLSX 与 CSV：保留正确的信息

工作簿与数据格式
格式用途保存前核对
XLSX主要工作簿格式，包含公式、工作表和格式。公式重算、工作表、图表、验证规则，以及在接收方软件重开。
CSV / TSV用于数据交换的分隔文本，不是完整工作簿。UTF-8 中文、分隔符、日期、前导零与数值精度。
XLS / XLSB / ODS旧格式或其他格式需要单独导入检查。不能从 XLSX 功能清单或导入的数值推断完整可编辑格式兼容。
XLSMExcel 启用宏的工作簿，与普通 XLSX 不同。上游说明导入时 VBA 会被丢弃并提示；不要用它保留宏工作簿。

将 CSV 转为 XLSX 时，先导入副本，检查 00123 这样的编号、中文表头和日期，再保存 XLSX 并重开。CSV 不能承载工作簿的图表、多工作表与格式。 微软格式丢失说明。

GridCraft 常见问题

GridCraft 免费吗？

上游项目采用 MIT／Apache-2.0 开源许可，本指南链接到公开发行文件；不能据此认定所有 ArtCraft AI 或第三方托管服务都免费。

可以在本站在线使用 GridCraft 吗？

目前不可以。本站现有托管编辑器为 PhotoCraft 与 CADCraft，本页提供 GridCraft 指南。上游 Web ZIP 可以另外托管，它不是可直接打开的官方试用链接。

Excel 工作簿和宏都能继续使用吗？

不能作此假设。须测试公式与保存结构，对应版本上游说明明确指出 VBA 限制。

有中文界面就代表完整支持中文文件吗？

菜单翻译、输入、字体排印、布局与导出是不同检查项，应使用实际样例验证。
