PhotoCraft 在线版常见问题

PhotoCraft 在线版可以免费使用吗？

可以。本站托管编辑器免费使用，已实测的 PNG 导入、图层编辑与导出流程没有付款步骤。

需要注册账号吗？

打开本站编辑器或跟随 PNG 教程无需注册本站账号。

可以不安装桌面应用直接使用吗？

可以。在支持的桌面浏览器中打开在线编辑器即可；首次访问仍需加载编辑器资源，包括约 25 MB 的 WebAssembly 文件。

本站实测了哪些文件格式？

新手流程已实测 PNG 编辑及简单两层 PSD 的保存和重开。复杂 PSD、文字、蒙版和 Photoshop 往返兼容性仍需单独检查。

在哪里下载桌面版 PhotoCraft？

可通过本站下载页选择官方 GitHub 发布中的 Windows、Mac 或 Linux 文件。

为什么浏览器中的 PhotoCraft 无法加载？

启动依赖图形支持及编辑器资源成功加载。可查看加载帮助中的浏览器和网络排查步骤。

本站会上传我的图片吗？

已实测的 PNG 编辑流程未观察到图片上传请求，本站也没有图片上传接口。托管请求、本地存储及外部服务说明见隐私政策。

FreePhotoCraft.online 是 PhotoCraft 官方网站吗？

不是。本站独立托管 PhotoCraft WebAssembly 构建并提供指南，不由 ArtCraft 运营，也不与其隶属。
