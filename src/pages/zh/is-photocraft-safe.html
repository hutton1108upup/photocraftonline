安装前怎样核对 PhotoCraft 下载文件

  1. 从上游 GitHub Releases选择发布版本及符合系统、架构的文件，避免不相关的镜像下载。
  2. 如果该发布提供校验文件，从同一个发布版本下载安装包及 SHA256SUMS.txt，在校验文件中找到完全相同的文件名。
  3. Windows 中右键点击下载文件，选择复制文件地址 / Copy as path；较旧系统可能需要按住 Shift 再右键。打开 PowerShell，把下方占位文字换成该完整路径，保留路径外的一层引号（复制结果已带引号时不要重复添加），然后执行。
  4. 把输出的 SHA256 值与校验文件中对应条目比较，字母大小写不影响结果。不一致时停止安装，重新核对版本、文件名和下载。
Get-FileHash -Algorithm SHA256 -LiteralPath 'PASTE_DOWNLOADED_FILE_PATH_HERE'
